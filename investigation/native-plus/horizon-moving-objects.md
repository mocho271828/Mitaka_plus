# 地平図の小天体・探査機

地平図では、彗星・小惑星などの小天体と、有効な PTH 位置を持つ探査機を描く。表示の種類・表示対象・名前の設定は太陽系画面と共有し、地平図内から点を選択できる。選択中の方位・高度と観測地点からの距離は描画と同じ観測地点・数値 JD の位置を使う。PPI の位置は推定しない。小天体・探査機の軌道線は地平図には表示しない。

小天体と探査機の日心 J2000 黄道座標 AU を赤道座標に変換し、同じ数値 JD の太陽中心から見た地球位置と、既存の地球赤道半径 6378.1366 km と WGS84 扁平率 1/298.257223563 を使う回転楕円体上で、緯度を測地緯度・標高を 0 と仮定した観測地点の地心位置を差し引いて測心方向を求める。snapshot と画面の JD が異なる間は描画しない。回転楕円体の幾何位置による日周視差を補正する。標高や地形、大気差、光行時間、時系変換は適用していない。地平線の描画と地形の基準形状は球面を使い、惑星本体の地平方向は従来どおり地心基準であるため、この補正と一致する地球形状を全面的に表示するものではない。[地点・日時別の実画面比較](ground-window-validation.md)では、旧版の注視方向と画面上の対象位置を分けて記録した。彗星評価は TDB、packed36 は物理時系未確定で、同じ数値 JD を渡しているため、厳密に同じ物理時刻を保証するものではない。

PTH の評価と表示可否は太陽系画面と同じ検証を使用し、記録期間外は既存処理に従い端点に固定する。地平図の選択詳細には原記録・補間・端点固定を区別して表示し、名前の表示を有効にした端点固定の点には「期間外・端点固定」を付ける。選択していない点で名前が非表示の場合は、点そのものから評価方法を判別できない。

これは native の実装仕様であり、旧 Windows Plus 全般との精度や期間外の端点処理の一致を保証しない。
