# 地形着陸標本化の中断

P1-3 の着陸高度は複数 LOD の交点を求める。新しい地点を要求すると、それまでの要求は取り消されるが、以前はパッチを開始する時点にしか取消を確認せず、1 パッチの全 LOD や三角形を調べ終えるまで後続要求が待つ場合があった。

`f27914c` を親とする本単位では、各 LOD の開始時、メッシュ生成の各行、着陸点との交点計算では 256 三角形ごとに取消を確認する。例外により途中結果を返さず、既存の世代管理が最新要求だけを採用する。原データの読み込み・検証中の I/O 自体は中断できない。LOD ごとの最大高さを選ぶため、表示中の LOD より高い位置に視点が浮く制約は残る。

地球・火星の同梱実データを含む地形試験は 57,472 checks 成功。生成途中と三角形走査途中の取消、実データ着陸の地形倍率 1・2・20、正負標高、controller の中断・再指定と不正入力は成功した。`make build`、`make test`、`make data-test`、`make reference-test` は成功。`make smoke` は成功し、地球・火星の着陸、Lua、再指定、地形倍率、移動中断、モード退出を確認した。旧 Plus との比較と実際の操作遅延は未実施。
