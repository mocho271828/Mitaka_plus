# Mitaka Plus 未再現機能の優先順位

## 対象と判定の読み方

対象は旧 Windows 版 Mitaka Plus 1.5.4 build101013 の、[機能対応表](../../vendor/mitaka/PLUS_FEATURE_MATRIX.md)にある通常 Plus の機能である。同表の判定時点・原典・行ごとの根拠と受入条件を併読する。同表は README、同梱スクリプトと 1.3.0 の説明書を基礎としており、実行ファイル内部の全機能を網羅した証明ではない。説明書のみの記載は 1.5.4 での存在・動作を別途確認する。

この一覧は同表の状態列が「部分」または「未実装」で始まる全 88 行を対象とする。ID の数字は同表の行番号で、同表を変更した場合は行番号も見直す。「部分」の中には実装欠落と、実装はあるが旧版との比較等が未検証のものが混在する。本表の状況は欠けている範囲に対する判定であり、行全体を未実装とするものではない。既存実装行、Pro 専用行、および仕様・安全性・出典の前提行は件数に含めない。各行の旧 Lua API は、GUI で類似操作ができても別途確認する。

**基準と限界:** 作成時の HEAD は `1af0eb4`。参照する機能表は過去の単位ごとの検証と作業ツリーの記録を含み、HEAD だけに対応した最新の完了証明ではない。現在並行実装中の変更は完了扱いにせず、結合試験と旧版比較の結果を得てから更新する。未検証は未実装の証明ではなく、旧仕様が未確定なら実装要否を先に確かめる。

## 優先順位と依存関係

- **P1-1** 太陽系から天の川銀河、大規模構造まで同一視点で連続移動・描画する基盤。3D 恒星も含める。視点・座標・スケールの接続が他機能の前提。
- **P1-2** 地上の星空に彗星・小惑星・探査機を接続する。位置評価済みの天体を観測地と時刻に連動させ、描画・選択・表示切替を確認する。
- **P1-3** 地形表示。地球・火星を旧 Plus との比較対象とし、データ欠落の診断と、同一日時での連続移動による地形要求の採用飢餓に対応する。日時を高速に連続変更する間は、表示の時刻整合を優先して基準球となる場合がある。月・水星は現行通常版にある追加候補であり、旧 Plus での提供自体は未確認。統合検証を含む。
- **P1-4** 36 byte 小惑星・TNO の軌道描画と、37 byte 形式の契約調査。36 byte は元期から一周期の数値 JD の軌道描画を実装し、離心近点角で等間隔に標本化する。標本時刻が区別できない場合は等時間に戻す。旧 Plus の標本規則は未確認。37 byte の Mitaka++ における解釈を確認したが、旧 Plus が実際に使用するかは未確認であり、使用を前提に位置や意味を推定しない。
- **P1-5** 宇宙・地上間の連続移動と mode API（CAM-01）。
- **P1-6** 視点の任意姿勢・ロールと姿勢 API、時間補間（CAM-02）。
- **P1-7** 地上の方位・高度の数値設定と補間 API（CAM-04）。
- **P1-8** Lua の移動・注視対象の拡張と名前・ID による選択（CAM-06）。
- **P2** 基本的な天文表示・移動・時刻・観測地と、再現に必要な安定性。P1 の各基盤を必要とする項目はその後に着手する。
- **P3** 旧 Lua・番組・状態・投影・メディア・カスタマイズなどの機能互換と、基礎機能の旧版照合。P1/P2 の対象機能の契約を利用する。
- **P4** 装飾・限定環境や旧形式への依存が大きい項目。必要性と旧版の実態を確認して着手する。

同一行が複数の作業に関係する場合、表の優先度は主たる着手順を示す。特に P1-1 の実装とその後の 3D 星座・ラベル、P1-2 と P1-4 の位置・軌道は別の受入条件として扱う。

P1-4 の軌道表示は既定でオフ。全件表示では操作が重くなる可能性があり、表示集合の対象のみに絞る `selectedOnly` を利用できる。旧等時間方式での測定として、Apple M2・macOS 26.6.2、7 AU の視点、800×600 RGBA bitmap に実際の `draw_small_bodies` を実行した測定では 0.762 / 0.753 / 0.776 秒だった。小惑星・TNO の軌道を有効、彗星とラベルを無効とし、packed 36 byte の実データ全 8,451 軌道を各 129 点で標本化した条件で 1,018,994 線分を描画した。生成と描画を含む単一バッファの測定プロセスの最大 RSS は 125,353,984 bytes。ウィンドウ表示時の FPS は未測定。

地形の根拠: 旧 `mitakaPlus.exe` には地球・火星の地形読込表示と `earth_topo.dat` / `mars_topo.dat` の文字列があるが、月・水星のファイル名は ASCII と UTF-16LE の走査では見つかっていない。別名や動的生成は排除できず、旧版の非対応を確定するものではない。手元の旧 Plus 原本に地形ファイルは見つかっていない（[地形データの出典記録](../../vendor/mitaka/native/core/TERRAIN_PROVENANCE.md)）。[国立天文台の現行通常版配布](https://4d2u.nao.ac.jp/mitaka/download/)には 4 天体のデータがあるが、その存在は旧 Plus で月・水星地形が提供されていた根拠にはならない。地球・火星の別配布データの使用は承認済みで、旧 exe で両データの読込・表示を確認した。原本との同一性や描画一致は未確認。

「不足」は機能表が示す未対応範囲、「未検証」は対応の有無や一致を確認できていない範囲、「仕様未確定」は旧版での提供や契約自体の確認が必要な範囲を指す。複数の状態が同居する行もある。

P1-8 の惑星対象指定は、即時指定でカメラの姿勢をリセットする一方、時間指定では開始時の姿勢を維持する。旧版の姿勢変更仕様は未確認であり、比較が必要。

P1-6 の銀河表示は、主画面の宇宙通常視点とカメラを共有する。`AppScripting.mm` は姿勢 API を `_solar` に渡し、`SolarScriptOrientation.mm` はそのカメラ姿勢を更新し、`SolarSystemView.mm` は同じカメラを銀河描画用に変換する。これはコード経路の確認であり、Lua から姿勢を変更した銀河表示の実行確認ではない。独立した銀河ブラウザには別のカメラがあり、姿勢 API の対象ではない。旧版との動作一致も未確認。

## 離陸から大規模構造までの比較条件

別チャットの[実画面調査メモ](/Users/kota/.codex/visualizations/2026/11/06/01a1b0d0-5ce2-7461-973b-a105224630cf/mitaka-flight-to-cosmic-structure-handoff.md)を現行実装に照合した。提供された公式画像と動画の見え方を参考にするが、撮影時の本家バージョン・姿勢・設定は未確定であり、旧 Plus の実機比較や画素一致の証拠とはしない。画像や動画の原本の所在はこの作業では未確認。

- **P1-1、まず連続性と精度:** 地球から 1 / 10 / 100 / 1,000 / 10,000 AU、1 / 100 / 1,000 / 10,000 光年と大規模構造へ往復する。入力中・停止直後・完成描画後の背景、可視性、位置、選択と最新 frame を確認する。天の川背景は地表と宇宙で同じ画像を連続投影し、既存 3D 銀河のフェード範囲に合わせて暫定的に距離減衰する。地平背景との画素比較と実画像を用いた自動検証を行ったが、実画面での見え方と旧 Plus の距離曲線は未確認。遠方 GAL/QSO の 1 AU 近接では pc 基準点と AU 差分を保持し、両カタログの原行 0 について描画画素・選択 ID・pan 往復を自動検証した。極端な値では精度に限界がある。実 SDSS 天体を追従しながら 1,000 AU と 1 pc を往復する自動 smoke で、各フレームのカメラ・追従・選択 ID を確認した。preview が対象を間引く場合もあり、全距離の描画収束と実画面操作は未確認。
- **P1-1、銀河の外観と識別:** 既存の放射・吸収モデルを使い、銀河系の正面・横向き、腕、バルジ、暗黒帯、太陽の位置と距離を検証する。モデル点の個別選択は実装済み。M13 等の名前は近接するモデル点へ付けず、球状星団の実 ID に対応させる。NBG/GC は選択情報に原 ID を表示し、一意な原 ID と既存名で Lua 対象へ往復する。表示半径は旧版の静的解析に基づき、距離と角直径の半分の積で求める。旧版との実動作比較は未確認。主画面での明示読込と全天図・地平図から銀河全景への遷移を実装し、実画面で球状星団 139 件・近傍銀河 2,371 件の読込表示を確認した。M31/M33/LMC/SMC 等の実 ID による画像・大きさ・名前の照合と、画像と点の切替は残件。Plus の形態コードと画像 atlas の対応は未確定。
- **P1-1、遠方分布:** SDSS 銀河の eClass を視等級とみなさず、通常 Mitaka 1.3.1 の 5 分類・B−V 色を基に preview / complete に配色を追加した。QSO の色は従来どおり。現行 GUI 実画面と旧 Plus の配色比較、色以外の点サイズ・測光・フェード・密度・preview と完成画像の連続性は未確認。preview と完成画像の重ね順を揃え、同一投影位置の SDSS/QSO 点は深度にかかわらず後描きの原行を選ぶ。同一画素内でも投影位置が異なる点や別レイヤー間の重なりは未解決。観測範囲外や空隙に架空の点を補わず、実データの原行・出典・選択 ID を保持する。
- **後続の既存単位:** オールト雲は P2/OBJ-11 で同梱通常版の由来を調べた再現可能な模式雲として扱い、1 万 AU 付近と前後の往復を検証する。3D HIP の名前は P2/STAR-02、色・明るさは P3/STAR-05 で既存の HIP ID と測光を使用し、無効視差を架空距離にしない。距離リングの色と万・億表記は P3/GRID-02、名前・軌道のフェードは P4/DRAW-01、地球の昼夜境界・夜側・大気の比較は OBJ-02/03 に含める。

## 更新方法

機能ごとの実装を完了扱いにする前に、上記機能表の受入条件、対象データを用いた統合試験、旧版比較の結果をそれぞれ記録する。未確認だった旧仕様が判明した場合は、実装の要否を見直し、根拠とともに対応行を更新する。優先順位の変更は影響と依存関係を併記する。

### P1-1 距離補間の仮定と残検証

`Camera.zoom` と `setZoomTo` / `setZoomLogTo` の距離は pc、時間省略時は `Camera.duration` を使う。旧版の時間曲線は未確認のため、前者は距離、後者は距離の自然対数を時間に対して等速と仮定する。中断して再指定した場合は現在の距離から開始し、対象移動中の距離指定は距離成分だけを引き継ぎ、対象への移動・追従は継続する。後から対象移動を開始した場合は距離補間を中断する。手動操作・状態復元・表示モード切替・スリープ・データ再読込では旧補間を中断する。静止地表と地平図では距離設定・補間を拒否する。独立した全天図は旧 Plus のモードとの対応が未確認で距離表示にも接続されていないため、距離操作を拒否すると仮定する。`Camera.zoom` が宇宙空間モードの距離である根拠は [旧資料監査](../../vendor/mitaka/investigation/native-plus/local-ui-state-input-audit.md)を参照。航行中は現在の視点・姿勢を保って航行を中断し、宇宙視点から補間する。航行解除後の軌道視点で始点または終点が無効になる場合は、航行状態を変更せず拒否する。地球・月モードでは既存の内部侵入防止に従い、各時点の距離が天体表面外に制限される場合がある。従来の native 直接代入は追従を解除していたが、旧資料は対象天体からの距離とするのみで追従解除を規定していない。距離操作が対象の追従を壊さないよう、直接代入・補間とも追従を保持すると仮定する。保存はその時点の距離のみを対象とし、補間は復元しない。旧版との比較、実画面・実データにおける地上と宇宙の接続、スリープ・モード切替・再読込の実操作による中断は未検証であり、この項目は部分対応のままとする。

### P1-1 地平図 FOV の仮定と残検証

旧資料から全角・半角と縦横の区別を確定できず、縦方向の全画角と仮定する。`Camera.fov` と `setFovTo` は地球の地平図で有限な `0 < fov <= 90` 度を受け付け、補間時間省略時は `Camera.duration` を用いる。起動時は既存表示の 180 度を読み返す。混合投影中、宇宙・全天図・非地球 3D 地表では操作を拒否する。状態保存は 1 度未満も維持し、旧 v9 の倍率からも復元する。極小画角では描画計算の下限を適用し、混合投影や極付近では微小な未解決線分を省略するため画素誤差は保証しない。旧 Plus との比較は未実施。5 種の全体検証に成功し、実画面で同梱 HIP 117,956 件・地平図・45° 復帰を確認した。詳細は [設計](fov-projection-design.md) と [検証記録](../../VALIDATION.md)を参照。

### P1-1 天の川点群の選択

点 ID は出典モデル内の群と 0 始まりの原順 ordinal で、無効点の除去や重複座標によって再採番しない。モデル交換時や非表示時などには選択を解除し、離陸・他対象への切替などでも古い追従を解除する。点の選択状態は現行 session v9 に保存しない。近傍の既存カタログ名との対応はデータから裏付けられないため行わない。自動テストで原順、間引き、変換、選択順位、無効値、キャンセル、画像生成失敗、透明、モデル交換を確認した。実データの操作・旧 Plus との比較は未実施であり、詳細と仮定は [選択設計](our-galaxy-point-selection-design.md)を参照。
