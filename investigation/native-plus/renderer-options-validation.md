# UI-04: 描画品質ダイアログの検証

確認日: 2026-11-07（JST）。

## 実装範囲

- 「表示 → 描画品質 → 描画品質の設定…」から既存4項目（アンチエイリアス、点、線、文字）のダイアログを開く。
- `RendererOptionsController` は AppKit の既存設定画面と同じ Dark Aqua、18 pt の外側余白、標準チェックボックスと 11 pt の説明文を使う。変更は即時反映で、未適用の下書きは保持しない。
- 各操作の直前に現在の `RendererDisplayOptions` を読み、1項目だけ変更して既存 `setRendererDisplayOptions:` へ渡す。メニュー・Lua・JSON v9 / アプリ設定の復元は同じ setter を通り、表示済みのダイアログへ callback の再実行なしで同期する。
- 全体 AA をオフにしても点・線・文字の設定値は保持し、引き続き編集できる。実効値は既存の `renderer_antialias` の条件に従う。
- データ未読込・読込中は設定取得と適用を拒否し、理由を表示する。適用失敗時は最新の読み取り値へチェックを戻し、失敗後の操作や再読込で復旧できる。
- `RendererDisplayOptions`、既存の保存処理、AppKit を再利用し、新規依存、独自描画処理、独自保存形式を追加していない。

## 仮定と未対応範囲

専用画面の配置と即時適用はネイティブ版の設計であり、旧 Plus のオプションダイアログとの一致は未確認。操作スタイル、全操作設定、高品質文字の独立設定、旧 OpenGL との画素比較は今回の対象に含めない。UI-04 全体は部分実装を維持する。

旧 Plus との画素比較、Intel Mac / macOS 13 実機、sanitizer は今回未実施。画面4値の接続のみの変更で、新規描画・永続化・非同期処理を追加していない。
