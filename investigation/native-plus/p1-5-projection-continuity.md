# P1-5: 地平図から宇宙への投影切替

この記録は、地平図の投影を先に変え、その後に地表視点を動かしていた時点の設計である。2026-11-12 に実測した旧 Plus と、地球の移動と投影を同時に進める現行版の比較は[離陸・帰還の検証記録](../../VALIDATION.md#p1-earth-flight)を参照。


通常の地平図は経緯度投影で、太陽系画面は縦画角 45° の透視投影である。移動時は両者の投影を補間するが、レイヤーに差が残るため P1-5 は未完了である。

## 今回の実装

通常の地平図は従来のままとし、移動時だけ投影の補間値 `t` を 0 から 1 に変更する。地平図側の視点が移動する前に投影を変え、透視投影への到達後に地表から上昇する。降下では逆順とし、指定された移動時間内で両段階の所要時間を割り当てる。

共通の描画矩形において `u = 2x / width - 1`、`v = 1 - 2y / height`、`a = tan(22.5°)` とする。中心方向に対する画素の経度・緯度を、次の両端の間で連続補間し、既存の地平座標への逆球面回転に渡す。

| | 経度 λ | 緯度 φ |
| --- | --- | --- |
| 地平図 | `-u * π / zoom` | `v * π / (2 * zoom)` |
| 透視投影 | `atan2(-u * a * width / height, 1)` | `atan2(v * a, sqrt(1 + (u * a * width / height)^2))` |

恒星などの順投影は、この画素から方向への写像の逆を求める。経度から `u` を、次に緯度から `v` を単調探索すれば、点とラスタが同じ投影を使える。±π の継ぎ目と極は同じ表現に揃え、画面外の方向は描画しない。

移行用の投影を `HorizonView` の恒星、天体、選択表示、グリッドに渡し、`sky_background.mm` と `landscape_projection.cpp` の逆投影にも使用する。画像キャッシュのキーには投影状態を含める。星座線・星座絵は現在、球面回転後に経緯度投影の線分関数を直接使用しているため、変換後の画面座標で適応分割・クリッピングする。風景がないときの地平線以下の塗りつぶしも同じ逆投影に合わせる。

背景と風景のキャッシュには投影係数を含め、補間中は最大辺 512 ピクセルで同期再生成する。太陽系側の背景も飛行中は同じ制限を使う。実機での応答速度は未確認であり、負荷が大きい場合は同期再生成を見直す必要がある。

投影だけを揃えても表示は連続しない。恒星、星座線・絵、天の川背景は地球の地表側と太陽系側で共有し、上昇完了後も地球の局所座標で表せる間は維持する。しかし、以下の差があるため P1-5 は未完了である。

- 地平図の風景パノラマには距離・形状情報がなく、太陽系側の球面地形と接続されていない。切替時に風景が変わる。
- 地平線下の天体の減光と、太陽系側の地形・惑星による遮蔽や実半径の表現が異なる。グリッドや記号天体も両画面で同一ではない。
- 地球の局所座標に変換できないロール付き姿勢や地球から約 10 億 km を超える距離では、共通星空から別の銀河描画へ切り替わる。
- 投影中の線分の画面外判定は標本点による近似で、画面端を極めて短く横切る線分を見落とす可能性がある。
- 実アプリで地球の離陸・降下時の投影変化を確認した。応答速度の測定と旧版との見た目の比較は未実施。

地形要求は非同期で公開される。移動開始時に古い太陽系模式図を表示しないよう旧シーンを破棄する修正を入れたが、地形更新中のカメラ追従と日時の整合も継続して確認する。
