# 地上 FOV と投影の設計・実装記録

## 対象と仮定

P1-1 の地球地平図と非地球 3D 地表を対象に、`Camera.fov` と `Camera:setFovTo` を投影、描画、選択、状態保存へ接続する。旧資料の 0〜90° が縦・横、全角・半角のどれかは未確認のため、**縦方向の全画角**と仮定する。設定値は有限かつ `0 < fov <= 90` 度。0° は投影を定義できないため拒否する。45° は復帰操作の値であり、起動視野を変更しない。

地平図の初期値は従来の表示を維持して 180° を返すため、読み戻し範囲と設定範囲は異なる。`Camera.zoom` はこれとは別の宇宙距離であり、非地球地表での既存 zoom 操作は観測高度を変更する。

## 投影と選択

地平ビューの正本は `HorizonViewport.vertical_fov_deg` とし、射影・逆射影と背景 raster が同じ値を使用する。円筒投影では縦の全画角であり、地上・宇宙間の移行中は太陽系カメラの透視画角と角度を補間する。Lua の FOV は地球地平図の円筒投影時と非地球 3D 地表の静止時に操作でき、移行中や宇宙・全天図では拒否する。

星座線、格子、風景などを同じ投影へ接続する。極端に小さい正値を保存・読み戻せる一方、数値精度のため描画計算は 1e-9° を下限とする。極小画角の混合投影や極付近では、微小な未解決線分を省略する場合があり、画素誤差は保証しない。実画面では同梱 HIP 117,956 件を使用し、地平図と 45° 復帰を確認した。旧 Plus の描画比較は未実施。

## 線分描画の性能と限界

地平図の星座線・格子と星座絵の線分は画面外と判定できる区間を早期に除外し、残りを幅優先で細分化する。混合投影では可視範囲内の標本と中間誤差を使い、小さい未解決区間を打ち切って他の区間に評価予算を残す。これは狭視野での無用な再帰を抑える実装上の改善であり、実測によるフレーム時間や原版比の性能保証ではない。

標準設定は線分ごとに評価数 8,193、深さ 48、元座標の幅 2° 以下、標本点の画面誤差 0.25 ピクセルを用いる。評価数・深さの上限や混合投影の打ち切り条件で未解決区間は直線で補わず省略する。0.25 ピクセルは標本点に対する判定値であり、曲線全体の厳密な誤差保証ではない。連続する省略区間の合計長にも保証はないため、極小画角、極や投影境界付近などで描画欠落が生じ得る。

## Lua、操作と状態

`setFovTo` は画角を線形補間し、時間省略時は `Camera.duration` を使う。再指定時は現在位置から始め、FOV 専用タイマーによって姿勢補間と独立させる。地平図の手動視点操作、星座への移動、スリープ、モード切替、データ再読込、状態の復元成功などで FOV 補間を中断する。不正値や不正な状態復元では実行中の補間を維持する。メニューから 45° に即時復帰できる。

JSON v9 の `horizon_viewport.fov_deg` は 1° 未満を含む正の角度を保持する。旧 v9 でこの項目がない場合、既存の `zoom` から `180 / zoom` として読み込み、`zoom = 1` を 180° に復元する。保存時は旧 `zoom` フィールドも出力するが、1° 未満の正確な値は `fov_deg` に保持する。投影混合率は従来どおり保存せず、円筒投影として復元する。

## 検証状況と残課題

射影・逆射影・raster、星座線と地平図の選択、Lua の値・補間と操作の中断、JSON の旧形式復元と小画角の往復を対象に試験を追加した。5 種の全体検証は成功し、結果は [検証記録](../../VALIDATION.md) に記録する。旧 Plus との比較は未実施である。

非地球の 3D 地表ではカメラの縦全画角を、射影・視線・pan、地形の視錐台、背景と銀河のキャッシュ、および恒星・星座の描画と選択へ渡す。地表で指定した画角は移動開始・中断・着陸の間も維持すると仮定する。地表位置を含むセッション復元は未対応で、旧 Plus と非地球地表の手動 GUI 比較は未実施。P1-1 全体は銀河点群選択などの残作業も含め部分実装である。
