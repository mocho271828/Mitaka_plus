# 未実装・未対応機能一覧

## 対象と読み方

[Mitaka Plus 機能対応表](../docs/compatibility/PLUS_FEATURE_MATRIX.md)を基に、Windows 版 Mitaka Plus **1.5.4 build101013** に対する macOS ネイティブ版の未対応部分と互換性上の制約を整理したものです。作成日: 2026-11-13。

- 「未対応」は対応表で機能全体が未対応とされる項目です。読込など一部の下位機能が使える場合もあります。
- 「一部対応」は利用可能な機能がある項目です。未対応部分と、提供範囲・仕様差・未確認事項を分けて読む必要があります。
- 「未確認」「未確定」は未実装を意味しません。旧版との比較やデータ仕様の確認が必要な事項です。
- ID は対応表と共通です。旧版の典拠、利用可能な操作の詳細、更新後の対応状況は対応表を正とします。本一覧はソースコードの独立した実装監査ではありません。
- 実装予定、優先順位、対応期限を定めるものではありません。

## 3. 機能の未実装と区別する事項

### 対応済み機能に残る仕様差・未確認事項

対応表が「対応」とする項目は、上の未対応一覧には含めていません。ただし、次の制約は利用時に注意が必要です。

| ID | 事項 |
| --- | --- |
| OBJ-01 | 太陽・惑星・月の形状と照明は近似。 |
| STAR-01 | 太陽系3Dでは正の視差がある恒星を固定光度の点で表示し、固有運動は適用しない。 |
| LUA-03 | コンソールの変数は入力間で共有しない。履歴はメモリ内のみ。旧版との動作一致は未確認。 |

### 旧版仕様の調査・互換性判断

- **SPEC-01 / SPEC-02 / SPEC-10**: Windows 1.5.4 の同梱日本語説明書は1.3.0用で、説明書に索引のない API もある。旧 macOS Plus 1.0.0・Windows Plus 1.5.4・通常版 Mitaka 1.3.1 は区別する。
- **SPEC-03 / SPEC-04 / SPEC-05 / SPEC-11**: 距離、倍率、時間ステップ、風景の引数順には版や呼出元による差がある。差があるだけで未実装とは判定しない。
- **SPEC-06**: 旧説明書には見出しと本文で API の綴りが一致しない箇所がある。
- **SPEC-07**: 旧初期状態のパスは説明書と配布版で異なる。旧起動スクリプトの自動実行は未対応（STATE-03）。
- **SPEC-08**: 彗星の尾に関する README の未対応注記は1.3.0向け。1.5.4 の仕様は未確定（OBJ-08）。
- **SPEC-09**: `Scene.Background.black` と `Renderer.editOnCapturedBG` の通常 Plus での詳細は未確定。
- **SEC-03**: 任意のファイルや URL を開く旧 API は未対応。ローカルファイルの選択・参照解決はデータ形式ごとに扱う。

### 通常 Plus の対象外

次の機能は別製品 Mitaka Pro の範囲であり、通常 Plus の未実装機能とは数えません。

| ID | 機能 | 補足 |
| --- | --- | --- |
| PRO-01 | 水平分割・垂直分割・QuadBuffer の立体視 | 通常 Plus のアナグリフは別項目（RENDER-03）。 |
| PRO-02 | `Renderer.renderToFile` | Pro 機能。 |
| PRO-03 | `Renderer.captureToFile` | 通常版のスナップショット保存は一部対応（UI-03）。 |

## 更新方法

機能の実装・検証で対応状況が変わった場合は、まず[機能対応表](../docs/compatibility/PLUS_FEATURE_MATRIX.md)を更新し、同じ ID の本一覧も更新してください。未確認事項は、検証結果が得られるまでは対応済み・未実装のどちらにも断定しないでください。
