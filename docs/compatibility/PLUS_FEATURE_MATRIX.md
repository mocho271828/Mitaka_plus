# Mitaka Plus 機能対応表

Windows 版 Mitaka Plus **1.5.4 build101013** の機能を、macOS ネイティブ版で使える範囲と照らし合わせた表です。GUI 操作と Lua API は別々に記載しています。同じ名称でも、旧版と表示・数値・入力形式が異なる場合があります。

「対応」は記載した操作が使えるもの、「一部」は旧版の対象・操作・形式に制約があるものです。旧版の日本語スクリプト説明書は **1.3.0** 用です。典拠の R は `ReadmeWin_J.txt`、G は `scripts/gui.lua`、D は `doc/script_jp/` の各 HTML、I は `scripts/init.lua` を示します。数字は配布時のファイルの行番号です。[旧 Windows 版の配布元](http://orihalcon.jp/mitakaplus/)

画面操作は [GUI ガイド](../gui/README.md)、プロパティの型・単位・実行条件は [Lua ガイド](../gui/SCRIPTING.md)、ビルド後の確認方法は [テスト手順](../../CONTRIBUTING.md#テスト) を参照してください。
