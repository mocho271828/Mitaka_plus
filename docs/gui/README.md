# GUI の操作

主画面は、全天図・太陽系 3D・地平図の描画にウィンドウの表示領域全体を使います。ボタン列、天体一覧、操作説明は常時表示しません。

## メニューを開く

主画面の上端にマウスポインタを移動すると、操作メニューが天体表示に重なって現れます。メニューから離れると閉じ、天体の表示領域は変わりません。macOS のメニューバーからも同じ操作を選べます。

通常ウィンドウでも全画面でも、主画面の上端からメニューを開けます。全画面の切り替えは「ウィンドウ」→「主画面を全画面表示」、または ⌃⌘F です。

## 表示と移動

- 「操作」から、全天図・太陽系 3D・地平図を切り替えます。
- 全天図と地平図では、ドラッグで視線を動かし、スクロールまたはピンチで拡大・縮小します。
- 太陽系 3D では、ドラッグで回転、Option ドラッグでロール、Shift または右ドラッグで移動、スクロールまたはピンチで拡大・縮小します。
- 天体は画面上のクリック、または「操作」の太陽系天体選択から選びます。検索は「表示」→「天体ブラウザ…」（⌘F）を使います。
- 「操作」のカメラと飛行の項目から、選択天体への移動や離着陸を行えます。主画面の S キーでも着陸・離陸を切り替えられます。

## 詳細な設定と情報

「操作」→「操作パネル…」を開くと、日時の数値入力、恒星の等級上限、着陸地点、カメラ・飛行操作、データの状態を確認・変更できます。「選択天体の情報…」で選択中の天体の情報、「描画の情報…」で座標系や描画の診断を確認できます。パネルを閉じても主画面の表示と操作は続きます。

暦で日時を指定する場合は「時刻」→「カレンダー・固定時差…」を使います。時刻の再生・一時停止・ステップ操作は「時刻」メニューから選べます。再生速度などの詳細は「再生・日時の操作パネル…」から設定します。「日時情報を表示」は初期状態ではオフです。

データを選ぶ操作は「ファイル」→「データを開く…」（⌘O）、表示状態の保存は「ファイル」→「表示状態を保存…」（⌘S）です。画像の書き出しや Lua の実行も各メニューから利用できます。

## 本家との関係

本家 Mitaka は、通常のメニューバーと、必要なときに呼び出すスクリーンメニューを備えています。主画面の上端へのホバーでメニューを開く方式は、この macOS 版の操作仕様です。本家の操作方法は[公式マニュアル](https://4d2u.nao.ac.jp/wp-content/uploads/mitaka/manual/mitaka_manual_J.pdf)の 3.2.8 節と第 4 章を参照してください。

Lua の操作は [Lua ガイド](SCRIPTING.md)、対応するデータと旧 Plus との差は[機能対応表](../compatibility/PLUS_FEATURE_MATRIX.md)に記載しています。
