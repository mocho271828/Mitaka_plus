# 食の純計算の出典と数値契約

N13 の純 C++ kernel は、[公式 Mitaka 1.3.1](../sources/README.md) の円盤重なり率、影円錐、影軸と受影球の交点、RGB 乗数を採用する。純計算を先行実装した後、UNIT7 で表面・境界・円錐表示へ接続した。GUI の対象と制限は [食の描画](../gui/ECLIPSE_RENDERING.md) を参照。以下の初回検証件数は当時の純 kernel の証跡を保持する。

公式コードの MIT 許諾表示は `src/eclipse.cpp` に保持した。既存の `Vec3` と C++17 標準ライブラリだけを使う。元の OpenGL mesh・大域状態・描画依存は取り込まず、元の球幾何と数式を小さい関数へ分離した。既存依存に円盤重なりや食の円錐評価器はなく、この範囲のために新しい数値ライブラリは追加しない。

## 型と入力境界

`EclipseSphere` は中心位置と正の半径、`EclipseGeometry` は太陽・遮蔽体・受影体を明示する。全入力は同一時刻・同一直交座標系にそろえる。native の接続単位は J2000 黄道 AU を想定するが、kernel 自体は時系変換、暦表取得、天体名による半径補完を行わない。

中心・半径・角度比は有限値を要求する。球同士の接触・交差、球上または内部の視点、不正な色・隠蔽率は `invalid_argument`。中間距離・角度比・円錐頂点が表現範囲を超える場合は `out_of_range`。通常の未交差は `nullopt` または隠蔽率 0 として扱う。

## 円盤の重なり率と表面標本

`eclipse_obscured_fraction(r,d)` は、太陽の視半径を 1 に正規化した平面円盤の面積比を返す。`r` は遮蔽体と太陽の視半径比、`d` は視中心角距離と太陽視半径の比。光球の周辺減光や回折を含まない。

原式と同じ二つの円弧面積を加えるが、同心・内接・外接は先に分類する。原式が `r=1,d=0` で返す NaN を native は完全隠蔽の 1 とする。巨大な `r` で `r+1` が `r` に丸まる場合にも、半径差による分類を使い、`r=d=DBL_MAX` を完全隠蔽と誤判定しない。

部分重なりは小さい円の中心から共通弦までの距離を求め、共通弦の高さから `atan2` で円弧角を計算する。平方の差を因数分解し、細い円弧では `r²(θ−sinθ cosθ)` を次の級数で評価する。

```
(rθ)² θ [2/3 − (2/15)θ² + (4/315)θ⁴ − (2/2835)θ⁶]
```

切替は `θ<0.01`。次の項は `r²(4/155925)θ¹¹` で、この閾値では打切り誤差が double の通常の相対丸め誤差より小さい。先に `rθ` を掛け、巨大半径の二乗 overflow と小角での相殺を避ける。これは同じ円弧面積の評価方法を変更したもので、原版との演算順・bit 単位の一致は主張しない。最終面積は `min(1,r²)` を上限とし、許容した最終丸めだけを clamp する。

`eclipse_surface_sample` の視半径は公式と同じ `asin(R/distance)`。視中心角は `acos(dot)` の代わりに `atan2(|cross|,dot)` を使い、ほぼ同方向の角度を安定して求める。遮蔽体の中心が太陽より近い場合にだけ隠蔽率を計算する。受影面の法線・夜側判定は呼出し側の責務であり、この関数は暗い面に影を重ねるかどうかを決めない。

## 影円錐と軸の交点

`eclipse_shadow_cones` は `Rsun>Roccluder` の有限円錐だけを扱う。太陽から遮蔽体への単位軸を `n`、中心距離を `D` とすると、半開角の正弦は `(Rsun−Roccluder)/D` と `(Rsun+Roccluder)/D`。遮蔽体中心から頂点までの距離は、それぞれ `Roccluder/sin(angle)` になる。本影円錐の軸は頂点から太陽側、半影円錐は頂点から太陽と逆側を向く。

受影体中心が遮蔽体中心より太陽に近いか等距離なら `nullopt` を返す。これは公式 `calc_eclipse_info` 冒頭の候補フィルタを採用した条件であり、任意の大きな球配置について食の不存在を証明する一般的な物理判定ではない。続いて、受影球が半影円錐の候補範囲外なら `nullopt` とする。候補円錐が得られることと、影軸が受影球を横切ることも区別する。

等半径では本影が円柱へ退化するため未対応として拒否する。太陽より大きな遮蔽体の逆の円錐関係も未対応。円錐 mesh、有限の描画長、反本影の表示分類をこの型から自動生成しない。UNIT7 では候補判定前の同一式を `eclipse_occluder_cones` として分離し、GUI の有限面生成と共有する。既存の候補判定の挙動は維持する。

`eclipse_shadow_axis_hit` は遮蔽体中心を始点とする前方半直線と受影球の最初の交点を返す。原版のゼロベクトル sentinel を使わず、未交差は `nullopt` とする。原版は判別式 `D<=0` をすべて未交差にするが、native は接線を単一交点として保持する。原版にない負の交点距離の拒否も加えた。距離の二乗同士を引かず、軸方向と外積による垂直距離を分ける。

## 色の適用境界

`eclipse_shadow_multiplier(f,c)` は公式の `GL_ZERO, GL_SRC_COLOR` に対応する RGB 係数 `1−(1−c)f` を返す。`f` と色の各成分は [0,1]。月の赤い影色 `(0.3,0,0)` は公式呼出し側の初期値として確認したが、kernel は天体名を解釈せず、色を必須入力とする。描画層と複数遮蔽体の乗算合成は GUI binding の責務とする。

## 検証

2026-10-30、strict C++17 の arm64 通常・arm64 ASan/UBSan・x86_64 で全実行が exit 0。各構成で `test_eclipse` は **10,179 checks PASS**、公式抽出比較は **7,993 checks PASS**。公式比較の最大絶対差は全構成 `1.6320278461989801e-14`、判定上限は `5e-13`。これは数値式の比較であり、天体暦や観測との精度保証ではない。

独立検算は円弧公式を使わず、共通縦断面の長さを 200,000 区間の中点積分で求めた。30 個の部分食条件を絶対差 `2e-7` 以内で検証する。等半径レンズの解析値、接触の `nextafter` 両側、巨大・微小比、距離に対する単調性、座標回転・平行移動・尺度変更、円錐頂点と軸交点の解析値、異常入力も検証した。

移植時に公式版の関数と8半径比 × 999部分重なり条件を照合した。同心円で原版が NaN、native が 1 になる条件は通常テストにも固定した。

## 今回の対象外

受影体の扁平率、旧版の三角形分割、模式半径、地平図での投影は kernel の責務に含めない。UNIT7 の表面境界・円錐・組合せ登録・四フラグと Lua/session の接続は GUI と App 層が担う。地上から見た空・大気の食による暗化はまだ残る。球幾何の成功を食表示全体の完了と扱わない。
