# Gate: ビルドと検証

## 目的

変更した挙動を利用者と同じ入口から検証できるようにする。

## 判定条件

- [ ] ビルド・実装の変更はルートの `make build` と `make test` で検証する。
- [ ] データ・同梱実装の変更は `make data-test`、起動や描画の変更は `make smoke` でも検証する。
- [ ] ドキュメントの変更では、記載したコマンドとリンク先を実際のツリーに照らして確認する。
- [ ] ガイド・仕様は `docs/` の索引からたどれ、公開文書内のリンクはクローンで取得できるファイルまたは公開 URL を参照する。
- [ ] PR または作業報告で実施した試験の結果を示し、実機・画面・他のアーキテクチャなど未確認の範囲を区別する。

## 不合格条件

- [ ] ビルド生成物、作業用ログ、認証情報を変更に含める。
- [ ] 過去の結果や実行していない試験を今回の成功として記録する。

## 判定

YES / NO
