# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [ ] Git の登録対象はソース・文書・設定・submodule 参照のみである。
- [ ] 既存の天文データ、独自追加データ、画像、旧アプリ、Wine 環境、認証情報を Git に登録していない。
- [ ] データを利用する処理は `DATA_ROOT` の指定先を読み取り専用で参照し、変換・移動・更新しない。
- [ ] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
- [ ] GitHub の Mitaka_plus と参照先 Mitaka は両方 Private である。
- [ ] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
- [ ] Lua は信頼済みローカルスクリプトの明示選択、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。
- [ ] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。
- [ ] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。
- [ ] 小天体の軌道標本上限超過は原記録を削らず拒否する。JPL 彗星の TDB 軌道と 36 byte 小惑星・外縁天体の数値 JD による位置評価を区別する。
- [ ] 探査機の PTH 元標本を保持し、範囲外の外挿や無効標本を跨ぐ線の補完をしない。表示契約が未確定の PPI を PTH と同じ描画対応に含めない。
- [ ] 星座の略号と同略号の複数図形を保持し、個別表示集合への対応を CAB/CDF 星座絵・景観の実装完了と説明しない。

## 不合格条件

- [ ] 明示的な追加許可なしに既存データ・原本を削除・上書き・再配布する。
- [ ] 旧 Mitaka_plus 全体を MIT ライセンスとして扱う。
