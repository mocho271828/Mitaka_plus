# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [ ] 動作に必要な Plus 版の天文データ・画像・関連ファイルは `resources/` にあり、他リポジトリや旧アプリのパスを必要としない。
- [ ] `resources/` 内の動作に必要なデータと画像は Git に登録され、clone に含まれる。
- [ ] 元データは削除・上書きせず、同梱したデータは原本と比較して内容の一致を確認している。
- [ ] 旧アプリ、Wine 環境、認証情報、ビルド生成物を Git に登録していない。
- [ ] データを利用する処理は選択された `DATA_ROOT` を読み取り専用で参照し、変換・移動・更新しない。
- [ ] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
- [ ] リポジトリの公開範囲は変更していない。
- [ ] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
- [ ] Lua は信頼済みローカルスクリプトの明示選択、コンソールのローカル入力の明示実行、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。
- [ ] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。
- [ ] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。
- [ ] 小天体の軌道標本上限超過は原記録を削らず拒否する。JPL 彗星の TDB 軌道と 36 byte・個別楕円の小惑星・外縁天体の数値 JD による位置・軌道評価を区別し、後者の物理的時系と旧版の軌道標本規則を未確定として扱う。個別楕円では有限の a > 0 と 0 <= e < 1 を条件に、明示された有限の n > 0 を使用し、n がなければ a から導出する。n のみの指定、非楕円、37 byte は位置を返さず原文と診断を保持し、旧 float 丸め・番号上書きとの差を記録する。
- [ ] 探査機の PTH 元標本を保持し、範囲外の外挿や無効標本を跨ぐ線の補完をしない。表示契約が未確定の PPI を PTH と同じ描画対応に含めない。
- [ ] 星座の略号と同略号の複数図形を保持し、全天図・地平図の CAB 星座絵への対応と、未対応の 3D 星座絵を区別する。
- [ ] 観測地点の全出典、CAB の全点・index、emmap の原 bytes を共通 loader で保持し、公開データによる置換や元画像の再保存を行わない。
- [ ] 地形・銀河は選択した版の原本を使い、欠損を別版から補わない。ただし、ユーザーが使用を承認した国立天文台の公式別配布による Earth・Mars 地形データは出典を明示して利用できる。旧 Plus のデータとの同一性が未確認であることを示し、月・水星へこの例外を拡張せず、第三者への再配布許可を推定しない。風景画像の失敗を別定義への再選択で隠さない。

## 不合格条件

- [ ] 既存データ・原本を削除・上書きする、または許諾が未確認のまま公開範囲を変更する。
- [ ] 旧 Mitaka_plus 全体を MIT ライセンスとして扱う。
