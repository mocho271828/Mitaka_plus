# Gate: 共通実装と依存関係

## 目的

共通実装の配置、状態保存、Lua の実行条件を維持する。

## 判定条件

- [ ] コアと GUI は `vendor/mitaka/native/` にあり、Git submodule と外部リポジトリの取得なしにビルドできる。
- [ ] 外部から実装を取り込む変更には採用元と対象範囲があり、新しい依存には導入理由がある。
- [ ] GUI・Lua・状態保存で共有するカメラ、描画、時刻は共通のモデルで扱う。セッションの変更は JSON v9 の既存の省略可能項目を読み込める。
- [ ] 状態復元は出典、ID、数値範囲を全体の適用前に検証し、再生を停止して復元する。HTML の信頼と Lua の実行状態は保存しない。
- [ ] Lua は同梱した固定版の SHA-256 を検証して helper に静的リンクする。実行の入口は明示したローカルコードまたは信頼済みローカル HTML のユーザー操作に限る。

## 不合格条件

- [ ] 遠隔文書・フレーム・ページ遷移先がローカル HTML の Lua 実行権限を引き継ぐ。
- [ ] 同じ状態や描画処理をルートのラッパーに別実装する。

YES / NO
