# Gate: 共通実装と依存関係

## 目的

Mitaka と Mitaka_plus の共通実装の分岐と、取得時の意図しないバージョン変更を防ぐ。

## 判定条件

- [ ] `vendor/mitaka` は Git submodule であり、`.gitmodules` の URL が `https://github.com/mocho271828/Mitaka.git` である。
- [ ] submodule の gitlink は Mitaka のリモートに存在するコミットを指す。
- [ ] Plus に共通コア・GUI のソースを複製せず、Makefile は submodule の既存ターゲットへ委譲する。
- [ ] 新たな依存を追加した場合、必要性と既存依存では不十分な理由を記録している。
- [ ] README に現在の実装の由来と、旧 Mitaka_plus の公式ソースを含まないことを明記している。
- [ ] Lua は共通実装の固定 SHA-256 と同じ公式ソースを使用し、helper へ静的リンクする。独自の Lua 処理系や外部 dylib の実行依存を追加しない。
- [ ] 旧 Plus の互換状況は共通の機能対応表を参照し、未対応のある状態で全機能完了と記載していない。
- [ ] HTML の Lua 呼出しを追加する場合、明示的に信頼したローカル HTML だけに許可し、オンライン文書・フレーム・遷移先から実行させない。
- [ ] HTML の実行は同一読み取りの内容・ファイル識別・メインページ・表示世代を検証し、通常リンク操作やファイル変更で信頼を失効させる。ページ JavaScript・Flash を有効にしない。
- [ ] 描画品質、小天体・衛星の設定と表示集合、軌道標本化、探査機表示、星座集合・星座絵、恒星名選択・明るさ、地球層・大気は共通モデルを使い、全画面/About は共通ウィンドウ処理へ委譲する。
- [ ] 単位6の JSON v6 の保存範囲と旧開発版 v1〜v5 の拒否を記載する。復元は停止状態とし、一時的な小天体・衛星・探査機のクリック選択、全画面・HTML 信頼・実行状態を復元しない。
- [ ] JSON v6 は未知・重複 ID、参照出典の SHA-256・バイト数、軌道標本上限などを全体の適用前に検証し、失敗した状態を部分適用しない。
- [ ] 種別表示の全体スイッチと表示集合への限定を区別し、名称・軌道もその可視性に従う。旧 Lua の英語名を使う集合 API を、確定した名前解決なしに対応済みと記載しない。
- [ ] JSON v6 の恒星名 HIP は読込済み名称表で検証し、明るさ・地球層・大気を全体検証後に復元する。不正入力で既存の明るさ補間や正常状態を失わない。

## 不合格条件

- [ ] 浮動するブランチの自動更新によって、記録した gitlink と異なる共通コードをビルドする。
- [ ] 共通実装を Plus にだけ複製・変更し、Mitaka 側との対応を失っている。

YES / NO
