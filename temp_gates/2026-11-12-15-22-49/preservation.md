# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [x] 動作に必要な Plus 版の天文データ・画像・関連ファイルは `resources/` にあり、他リポジトリや旧アプリのパスを必要としない。
  - 指定 DATA_ROOT の親に data・images・textures・spacecraft・scripts・media があり、実画面は --data-root で同梱データの複製を使用した。
- [x] `resources/` 内の動作に必要なデータと画像は Git に登録され、clone に含まれる。
  - git ls-tree -r HEAD -- resources は575件。地形2件は Git LFS で追跡される。
- [x] 元データは削除・上書きせず、同梱したデータは原本と比較して内容の一致を確認している。
  - 実画面用の resources 全575件のパスに過不足がない。通常573件（58,563,911 bytes）は実ファイルを Git blob/checkout と照合し、地形2件はサイズと SHA-256 が LFS ポインターに一致した。旧アプリ原本全体の再照合は今回の対象外。
- [x] 旧アプリ、Wine 環境、認証情報、ビルド生成物を Git に登録していない。
  - git status と diff --name-only を確認。検証画像・動画・生のウィンドウ情報・一時ツールは Git 管理外の local/ のみ。登録対象の verification/p1-1-window-roundtrip.tsv は状態と SHA-256 を含み、全172行のハッシュを実ウィンドウ画像と再照合した。RAW のウィンドウ情報・他アプリの情報・認証情報の列はない。
- [x] データを利用する処理は選択された `DATA_ROOT` を読み取り専用で参照し、変換・移動・更新しない。
  - データ入力は同じ resources を参照する --data-root。操作スクリプトの記録先と画像・ログの保存先を Git 管理外の local/verification/p1-1-window/ に分離した。
- [x] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
  - git diff HEAD -- resources vendor/mitaka/sources は空。README 末尾はコードの許諾からデータの再配布条件を推定しないと明記する。
- [x] リポジトリの公開範囲は変更していない。
  - gh repo view --json visibility が PUBLIC と返した。利用者が変更した既存の公開設定。今回は設定を更新していない。
- [x] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
  - 同梱版の星表と地形を使用し、外部カタログの取得や件数の置換はしていない。通常ファイル573件は Git blob と内容一致。
- [x] Lua は信頼済みローカルスクリプトの明示選択、コンソールのローカル入力の明示実行、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。
  - 既存の明示実行 Lua コンソールからカメラを操作した。ScriptController / ScriptWorker と自動読み込みの経路に差分はない。
- [x] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。
  - 契約は IMPLEMENTATION_POLICY の出典・原行 ID による表示集合、session_layers_json.mm の出典 SHA / byte_count にある。該当するデータ・復元処理の差分は空。
- [x] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。
  - 追加衛星の登録・親位置を扱う core/src/satellite_*.cpp に差分なし。元データの全件照合で該当カタログも一致。
- [x] 小天体の軌道標本上限超過は原記録を削らず拒否する。JPL 彗星の TDB 軌道と 36 byte・個別楕円の小惑星・外縁天体の数値 JD による位置・軌道評価を区別し、後者の物理的時系と旧版の軌道標本規則を未確定として扱う。個別楕円では有限の a > 0 と 0 <= e < 1 を条件に、明示された有限の n > 0 を使用し、n がなければ a から導出する。n のみの指定、非楕円、37 byte は位置を返さず原文と診断を保持し、旧 float 丸め・番号上書きとの差を記録する。
  - core/src/minor_planet_* と small_body_orbit_* を変更していない。36 byte・個別楕円と未確定の37 byteを分ける統合元 0269774 の契約を維持。
- [x] 探査機の PTH 元標本を保持し、範囲外の外挿や無効標本を跨ぐ線の補完をしない。表示契約が未確定の PPI を PTH と同じ描画対応に含めない。
  - core/src/spacecraft_trajectory*.cpp と同梱探査機データの差分は空。PTH と PPI の判定は IMPLEMENTATION_POLICY の探査機の条件のとおり。
- [x] 星座の略号と同略号の複数図形を保持し、全天図・地平図の CAB 星座絵への対応と、未対応の 3D 星座絵を区別する。
  - constellation_art*.cpp 等の loader・星座データの差分はない。対象ビューごとの対応範囲は PLUS_FEATURE_MATRIX に記録されている。
- [x] 観測地点の全出典、CAB の全点・index、emmap の原 bytes を共通 loader で保持し、公開データによる置換や元画像の再保存を行わない。
  - 観測地点・CAB・emmap を含む同梱575件の照合が一致した。loader および元画像の差分は空。
- [x] 地形・銀河は選択した版の原本を使い、欠損を別版から補わない。ただし、ユーザーが使用を承認した国立天文台の公式別配布による Earth・Mars 地形データは出典を明示して利用できる。旧 Plus のデータとの同一性が未確認であることを示し、月・水星へこの例外を拡張せず、第三者への再配布許可を推定しない。風景画像の失敗を別定義への再選択で隠さない。
  - 実体の Earth 81,822,538 bytes と Mars 213,945,124 bytes の各 SHA-256 は今回の LFS ポインターに一致。銀河データを含む通常ファイルも照合した。外部から地形や銀河を補完する経路は追加していない。

## 不合格条件

- [ ] 既存データ・原本を削除・上書きする、または許諾が未確認のまま公開範囲を変更する。
  - 入力を検証用の別ディレクトリに展開し、変更対象から resources と公式原本を除外した。GitHub の公開設定の更新操作なし。
- [ ] 旧 Mitaka_plus 全体を MIT ライセンスとして扱う。
  - README「保存範囲と利用条件」はコードと旧版データの再配布条件を分けて記載する。ライセンス文書への差分なし。

## 判定

YES
