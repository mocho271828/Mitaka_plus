# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [x] 動作に必要な Plus 版の天文データ・画像・関連ファイルは `resources/` にあり、他リポジトリや旧アプリのパスを必要としない。
  - 根拠・残件: UNIT8 の同梱構成・検証は VALIDATION.md 15–20 行。今回増えた Earth/Mars は TERRAIN_PROVENANCE.md 66–77 行に出典・同梱先を記載し、未提供の Moon/Mercury を明示。
- [x] `resources/` 内の動作に必要なデータと画像は Git に登録され、clone に含まれる。
  - 根拠・残件: 親担当が Git LFS fsck および今回 commit の新規 clone で build・test の成功を確認。
- [x] 元データは削除・上書きせず、同梱したデータは原本と比較して内容の一致を確認している。
  - 根拠・残件: UNIT7 原本比較と UNIT8 の同梱資源 885 件の SHA-256 比較は VALIDATION.md 20、28 行。今回原本未変更を親担当が確認し、追加 Earth/Mars と公式 ZIP 展開物の SHA-256 一致を TERRAIN_PROVENANCE.md 70–75 行に記録。
- [x] 旧アプリ、Wine 環境、認証情報、ビルド生成物を Git に登録していない。
  - 根拠・残件: 既存の採用時 gate・登録範囲は VALIDATION.md 20、30 行。今回の git status に資源・旧実行環境・認証情報・ビルド生成物の追加はない。
- [x] データを利用する処理は選択された `DATA_ROOT` を読み取り専用で参照し、変換・移動・更新しない。
  - 根拠・残件: 既存の読み取り専用契約と採用時検証に加え、今回変更は日時・描画・軌道演算が中心で resources に差分なし。VALIDATION.md 20、28 行。
- [x] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
  - 根拠・残件: README 118、121 行は各権利表示を参照し、データ許諾をコードから推定しない。権利表示の今回の差分はない。
- [x] リポジトリの公開範囲は変更していない。
  - 根拠・残件: 親担当がリモート private を確認。今回の公開範囲変更なしとの報告。
- [x] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
  - 根拠・残件: resources に Git 差分なし。README 27–29、68 行に独自データ・未対応行の保持を記載。
- [x] Lua は信頼済みローカルスクリプトの明示選択、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。
  - 根拠・残件: README 21、120 行に明示的な信頼とユーザー権限を記載。今回 Lua 自動実行経路の追加はない。
- [x] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。
  - 根拠・残件: README 27–28、338 行と UNIT7 の表示集合・出典検証（VALIDATION.md 24–28 行）。今回差分を含む make test・data-test は親担当が成功を確認。
- [x] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。
  - 根拠・残件: README 19、28 行と UNIT7 検証（VALIDATION.md 24–28 行）。変更された日時・衛星処理を含む make test と data-test は親担当が成功を確認。未確定の時系・精度は保証しない。
- [x] 小天体の軌道標本上限超過は原記録を削らず拒否する。JPL 彗星の TDB 軌道と 36 byte 小惑星・外縁天体の数値 JD による位置・軌道評価を区別し、後者の物理的時系と旧版の軌道標本規則を未確定として扱う。
  - 根拠・残件: 今回の軌道予算・記録保持・時系は SMALL_BODY_PROVENANCE.md と README 27 行。局所回帰は通常・ASan/UBSan と実データ 8,451 軌道で通過（VALIDATION.md 9–10 行）。
- [x] 探査機の PTH 元標本を保持し、範囲外の外挿や無効標本を跨ぐ線の補完をしない。表示契約が未確定の PPI を PTH と同じ描画対応に含めない。
  - 根拠・残件: README 29、330–332 行と UNIT7 の PTH 試験（VALIDATION.md 24–28 行）。日時更新を含む今回の make test と data-test は親担当が成功を確認。
- [x] 星座の略号と同略号の複数図形を保持し、全天図・地平図の CAB 星座絵への対応と、未対応の 3D 星座絵を区別する。
  - 根拠・残件: 星座の loader と表示集合は今回変更なし。VALIDATION.md 28 行の UNIT7 採用時検証、および README 38 行の対応範囲を参照。
- [x] 観測地点の全出典、CAB の全点・index、emmap の原 bytes を共通 loader で保持し、公開データによる置換や元画像の再保存を行わない。
  - 根拠・残件: 共通 loader の保全は UNIT7 と UNIT8 の既存原本・資源比較（VALIDATION.md 20、28 行）。これらの入力資源と loader は今回変更なし。
- [x] 地形・銀河は選択した版の原本を使い、欠損を別版から補わない。ただし、ユーザーが使用を承認した国立天文台の公式別配布による Earth・Mars 地形データは出典を明示して利用できる。旧 Plus のデータとの同一性が未確認であることを示し、月・水星へこの例外を拡張せず、第三者への再配布許可を推定しない。風景画像の失敗を別定義への再選択で隠さない。
  - 根拠・残件: 公式別配布は承認済み。TERRAIN_PROVENANCE.md 66–77 行で出典・hash・未確認事項・Moon/Mercury の除外・再配布条件を明示。風景の失敗時の扱いは変更なく UNIT7 検証記録（VALIDATION.md 28 行）を参照。
