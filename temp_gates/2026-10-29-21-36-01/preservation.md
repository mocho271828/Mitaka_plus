# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [x] Git の登録対象はソース・文書・設定・submodule 参照のみである。
- [x] 既存の天文データ、独自追加データ、画像、旧アプリ、Wine 環境、認証情報を Git に登録していない。
- [x] データを利用する処理は `DATA_ROOT` の指定先を読み取り専用で参照し、変換・移動・更新しない。
- [x] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
- [x] GitHub の Mitaka_plus と参照先 Mitaka は両方 Private である。
- [x] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
- [x] Lua は信頼済みローカルスクリプトの明示選択、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。
- [x] 追加衛星の原文・順序・重複を保持し、親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。未確定の時系・精度期間や探査機の未接続表示を対応済みと扱わない。

## 不合格条件

- [ ] 明示的な追加許可なしに既存データ・原本を削除・上書き・再配布する。
- [ ] 旧 Mitaka_plus 全体を MIT ライセンスとして扱う。

## 判定

YES

## 検証根拠

- 登録対象は文書・検証ログ・gate コピーと gitlink。元カタログ本文、画像、実行ファイル、Wine、生成物、認証情報は含めない。ログにはビルド出力・結果件数・合成 fixture の情報だけを保持し、秘密情報標識と NUL の混入がないことを確認した。
- `DATA_ROOT` は空白を含むローカル Plus の絶対 `data` パスを使い、読み取り専用の既存ターゲットへ渡した。原本変換・上書きはない。
- 著作権・許諾表示を変更せず、README でコードとデータの許諾を区別する。
- `gh repo view` の両リポジトリの `visibility: PRIVATE` を `verification/unit4-{source-private,private}.log` に保存した。
- 実データで衛星 340 行 / 330 位置、小天体 19,475 行 / 2,388 位置を確認。欠損・未確定行を削除せず、共通側の原本保全 16,365 files / 6,622,642,667 bytes / 465 symlinks、変更 0 の記録も参照する。
- ローカル Lua と信頼したローカル HTML からの実クリックに限定し、ユーザー権限のファイル・OS 操作を許可する非 sandbox の契約を README に説明した。
- 出典・JD ごとの衛星登録、親位置の一度だけの補正、物理時系・精度期間・衛星表面/自転・探査機 GUI の未対応を明記した。

詳細は [今回の検証記録](VALIDATION.md) と [リポジトリの記録](../../VALIDATION.md) を参照。
