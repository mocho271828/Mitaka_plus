# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [ ] 動作に必要な Plus 版の天文データ・画像・関連ファイルは `resources/` にあり、他リポジトリや旧アプリのパスを必要としない。  **一部確認:** 旧 workspace を読み取り拒否した隔離コピーの既定パスで `build`・`test`・`data-test`・`reference-test`・`smoke` が成功。未実行機能を含むすべての関連ファイルは未確認。
- [ ] `resources/` 内の動作に必要なデータと画像は Git に登録され、clone に含まれる。  **未確認:** `resources/` の通常ファイル 573 件はすべて Git index に登録済みだが、commit 後の clone を検証していない。
- [ ] 元データは削除・上書きせず、同梱したデータは原本と比較して内容の一致を確認している。  **一部確認:** 旧 Plus 原本の `data`・`textures`・`spacecraft`・`images`・`scripts`・`media` と `resources/` の各組を `diff -qr` で比較し差分なし（6 組すべて終了 0）。原本全体が作業前から変更されていないことまでは今回検証していない。
- [ ] 旧アプリ、Wine 環境、認証情報、ビルド生成物を Git に登録していない。  **未確認:** 今回この条件全体を検証していない。
- [ ] データを利用する処理は選択された `DATA_ROOT` を読み取り専用で参照し、変換・移動・更新しない。  **未確認:** 今回この条件全体を検証していない。
- [ ] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。  **未確認:** 今回この条件全体を検証していない。
- [ ] リポジトリの公開範囲は変更していない。  **未確認:** 今回この条件全体を検証していない。
- [ ] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。  **未確認:** 今回この条件全体を検証していない。
- [ ] Lua は信頼済みローカルスクリプトの明示選択、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。  **未確認:** 今回この条件全体を検証していない。
- [ ] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。  **未確認:** 今回この条件全体を検証していない。
- [ ] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。  **未確認:** 今回この条件全体を検証していない。
- [ ] 小天体の軌道標本上限超過は原記録を削らず拒否する。JPL 彗星の TDB 軌道と 36 byte 小惑星・外縁天体の数値 JD による位置評価を区別する。  **未確認:** 今回この条件全体を検証していない。
- [ ] 探査機の PTH 元標本を保持し、範囲外の外挿や無効標本を跨ぐ線の補完をしない。表示契約が未確定の PPI を PTH と同じ描画対応に含めない。  **未確認:** 今回この条件全体を検証していない。
- [ ] 星座の略号と同略号の複数図形を保持し、全天図・地平図の CAB 星座絵への対応と、未対応の 3D 星座絵を区別する。  **未確認:** 今回この条件全体を検証していない。
- [ ] 観測地点の全出典、CAB の全点・index、emmap の原 bytes を共通 loader で保持し、公開データによる置換や元画像の再保存を行わない。  **未確認:** 今回この条件全体を検証していない。
- [ ] 地形・銀河は選択した版の原本を使い、欠損を別版から補わない。風景画像の失敗を別定義への再選択で隠さない。  **未確認:** 今回この条件全体を検証していない。

## 不合格条件

- [ ] 既存データ・原本を削除・上書きする、または許諾が未確認のまま公開範囲を変更する。  **未確認:** この不合格条件の不存在を検証していない。
- [ ] 旧 Mitaka_plus 全体を MIT ライセンスとして扱う。  **未確認:** この不合格条件の不存在を検証していない。

## 判定

NO（合格保留）。各項目の未確認事項が残るため、gate 全体を合格とは判定しない。チェック済みの項目は記載された根拠の範囲で確認した。

## 今回の適用範囲と既存検証

今回の変更は共通コードと版固有資源の同梱、既定パス、Lua の同梱である。既存の機能契約全体を今回すべて再検証してはいない。未確認項目を今回の変更に由来する不具合と断定しない。

今回、隔離コピーの build・test・data-test・reference-test・smoke は成功（`/private/tmp/mitaka-validation.oy7txY/`）。これらの成功だけで各 gate の全条件の検証完了とは扱わない。
