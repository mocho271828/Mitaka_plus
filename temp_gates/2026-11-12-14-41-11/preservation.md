# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [x] 動作に必要な Plus 版の天文データ・画像・関連ファイルは `resources/` にあり、他リポジトリや旧アプリのパスを必要としない。
  - ルート Makefile の既定値は `resources/data`。README の起動手順は同じ親にある `textures`・`spacecraft` を参照し、旧 Wine のパスを要求しない。UI-07 の PDF/CHM はこの配布に含まれず、所在監査に記録した。
- [x] `resources/` 内の動作に必要なデータと画像は Git に登録され、clone に含まれる。
  - `git ls-files -- resources` は 575 件。`git lfs ls-files -n` に地球・火星の地形2件がある。大容量データの実体は Git LFS の取得対象。
- [x] 元データは削除・上書きせず、同梱したデータは原本と比較して内容の一致を確認している。
  - `ebca717` の `resources/` の Git ツリーと、今回全試験に使ったスナップショットのパス集合は575件すべて一致した。通常573ファイル（58,563,911 bytes）は作業ツリーとバイト単位で一致し、スナップショットから計算した Git blob ID も各登録値と一致した。地形2件は下記の LFS 照合で確認した。元の旧 Wine 配布物全体との新たな照合は今回実施していない。
- [x] 旧アプリ、Wine 環境、認証情報、ビルド生成物を Git に登録していない。
  - `git diff --name-status 8335aba ebca717` の全49ファイルを確認した。追加ログは LUA-04 の短い監査結果と同梱12本の相対パスによるハッシュ一覧。旧アプリ・Wine・認証情報・ビルド生成物や一時 fixture は差分にない。今回の `local/verification/pr8-integration/` は `git check-ignore` の対象で追跡ファイルは0件。
- [x] データを利用する処理は選択された `DATA_ROOT` を読み取り専用で参照し、変換・移動・更新しない。
  - 地形回帰は指定された `DATA_ROOT` から Earth/Mars のファイルを参照する。Lua 互換監査は原本のコンパイル前後で bytes を照合し、書込み試験には一時 fixture を使う。
- [x] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
  - 公式ソース・アーカイブ・同梱ライセンスの変更は採用差分にない。README「保存範囲と利用条件」と `native/core/TERRAIN_PROVENANCE.md` が地形の出典・許諾範囲を記録する。
- [x] リポジトリの公開範囲は変更していない。
  - 2026-11-12 JST に `gh repo view` で `PUBLIC` / `isPrivate=false` を確認した。所有者が事前に公開した状態で、今回の作業で visibility を設定する操作は行っていない。
- [x] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
  - 採用対象の各 commit の変更一覧には `resources/` が含まれない。`DATA_ROOT` を同梱データに向ける既存設定を使用する。
- [x] Lua は信頼済みローカルスクリプトの明示選択、コンソールのローカル入力の明示実行、または信頼したローカル HTML のユーザー操作によって実行し、ユーザー権限のファイル・OS 操作を許可することを説明している。通常のデータ読み込みからコードを自動実行しない。
  - `AppScripting.mm` のコンソール入力は GUI の実行操作から `runConsoleSource` に渡る。`SCRIPTING.md` はファイル・OS 権限と履歴操作を説明する。HTML は既存の明示信頼処理を経る。監査の `loadfile` は読み取った原本チャンクを呼び出さない。動作確認は検証 gate に記す。
- [x] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。
  - `session_layers.mm` の選択には `source_key` を保持し、`verify_sources` で現行ソースを照合する。今回の統合対象は小天体・衛星の loader と session identity を変更しない。
- [x] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。
  - `native/core/SATELLITE_ABSOLUTE_PROVENANCE.md` と `satellite_scene.cpp` が親の扱いを記録する。今回の入力・描画設定画面の変更は追加衛星の計算経路へ入らない。
- [x] 小天体の軌道標本上限超過は原記録を削らず拒否する。JPL 彗星の TDB 軌道と 36 byte・個別楕円の小惑星・外縁天体の数値 JD による位置・軌道評価を区別し、後者の物理的時系と旧版の軌道標本規則を未確定として扱う。個別楕円では有限の a > 0 と 0 <= e < 1 を条件に、明示された有限の n > 0 を使用し、n がなければ a から導出する。n のみの指定、非楕円、37 byte は位置を返さず原文と診断を保持し、旧 float 丸め・番号上書きとの差を記録する。
  - #8 の `minor_planet_position.cpp`・`minor_planet_orbit_path.cpp` と方針原本の条件を確認。`eb913ea` の個別楕円に `a59e2ad` が明示平均運動を追加しており、旧ローカル実装を重ねていない。
- [x] 探査機の PTH 元標本を保持し、範囲外の外挿や無効標本を跨ぐ線の補完をしない。表示契約が未確定の PPI を PTH と同じ描画対応に含めない。
  - 探査機の入力契約は `native/core/SPACECRAFT_POSITION_PROVENANCE.md` と `SPACECRAFT_TRAJECTORY_PROVENANCE.md` にあり、今回の変更対象に入力・補間処理は含まれない。
- [x] 星座の略号と同略号の複数図形を保持し、全天図・地平図の CAB 星座絵への対応と、未対応の 3D 星座絵を区別する。
  - `CONSTELLATION_ART_PROVENANCE.md` の CAB と追跡表 CONST-02 の宇宙空間での 3D 配置を照合した。火星・月の地表で星座絵を投影する #8 の回帰は別の対象。採用対象に CAB loader の変更はない。
- [x] 観測地点の全出典、CAB の全点・index、emmap の原 bytes を共通 loader で保持し、公開データによる置換や元画像の再保存を行わない。
  - `native/core/PLACE_CATALOG_PROVENANCE.md`・`CONSTELLATION_ART_PROVENANCE.md` とルート方針に元の出典と構造が記録されている。採用対象に `resources` の地点・CAB・emmap やこれらの loader の変更はない。
- [x] 地形・銀河は選択した版の原本を使い、欠損を別版から補わない。ただし、ユーザーが使用を承認した国立天文台の公式別配布による Earth・Mars 地形データは出典を明示して利用できる。旧 Plus のデータとの同一性が未確認であることを示し、月・水星へこの例外を拡張せず、第三者への再配布許可を推定しない。風景画像の失敗を別定義への再選択で隠さない。
  - Earth 81,822,538 bytes の SHA-256 は `a9082001c38ca0b3111d5f3dd7cf8abfb0b18cf581d4c1eb89589ea932030190`、Mars 213,945,124 bytes は `0e65c81ee8ba0d59312b28e4928ce95c45d389fe024cfc37685b1842d4db907e`。実行に用いた2ファイルの計算値は `ebca717` の LFS pointer と `native/core/TERRAIN_PROVENANCE.md` の出典値に一致し、`git lfs fsck` は終了0。統合後の火星降下回帰は実地形上 2 m の着陸で表示カメラが一致した。地球・火星の出典・許諾範囲は同文書にあり、他版の地形・月・水星・風景を調達する変更はない。

## 不合格条件

- [ ] 既存データ・原本を削除・上書きする、または許諾が未確認のまま公開範囲を変更する。
  - 作業対象の一覧に元データ、Wine prefix、権限変更は含まれない。
- [ ] 旧 Mitaka_plus 全体を MIT ライセンスとして扱う。
  - README「保存範囲と利用条件」はデータとコードの権利について別々に明記する。
