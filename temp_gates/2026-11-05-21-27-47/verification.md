# Gate: ビルド・検証・変更管理

## 目的

同梱コードとデータの渡し方を、再現可能なビルドと検証で確認する。

## 判定条件

- [ ] `make build` と `make test` が成功する。
  - 判定: NO。追加変更の初回ビルド失敗を修正後、make -j4 build は終了コード 0。make test は既存の失敗注入を含むため、ユーザー指示に従って今回未実施。
- [ ] データや同梱コードを変更した場合、同梱データを指定した `make data-test` と `make reference-test` が成功する。公式比較には CF96・自転・月・大気・食を含める。
  - 判定: NO。make data-test / make reference-test は、今回の変更に対する必要最小限の確認を優先し、未実施。過去の成功を今回の成功とは扱わない。
- [x] `DATA_ROOT` は絶対パスの `data` ディレクトリとして受け取り、コアのデータテストにはその親ディレクトリを渡す。
  - 判定: YES。ルート Makefile は絶対 DATA_ROOT を要求し、コアには親ディレクトリを渡す。
- [x] `DATA_ROOT` の既定値は本リポジトリ内を指し、データ不足の場合は手順を示すエラーで停止する。
  - 判定: YES。ルート Makefile は resources/data を既定とし、相対パス・必須データ欠落で説明付き停止を定義。
- [x] クリーンなビルドは Lua ソースのダウンロードや他リポジトリを必要としない。
  - 判定: YES。同梱 Lua ソースとオフライン構成の既存記録があり、依存の取得経路に今回変更なし。今回のクリーンビルド再実行はしていない。
- [x] 作業完了時に `git status`、変更ファイル、差分量を確認し、300 行以上の変更では原則 commit する。
  - 判定: YES。git status・変更ファイル・差分量を確認し、300 行以上の変更は途中実装として commit する。作業後の状態も確認する。
- [x] commit 前に `/simplifier-lai` skill の利用可否と依存関係を確認し、利用できない場合は報告する。
  - 判定: YES。exact /simplifier-lai は今回の利用可能 skill 一覧に存在しない。類似名 simplify-lai は LobbyAI 専用。Makefile 差分に新規ライブラリはない。最終報告は親担当が行う。
- [x] gate 検証用コピーに判定を記録し、実施したテストと未実施の確認を作業報告へ残す。
  - 判定: YES。現行 gate をこのディレクトリに複製し、実行済み・未実施の別を本記録に記入。最終報告は親担当が行う。
- [x] 追加衛星・描画品質・全画面・HTML を採用する場合、共通側の対応試験と採用 SHA を特定する。HTML helper の構成、実 OS 通知、実機・複数画面など未確認の範囲を成功扱いしない。
  - 判定: YES。採用元 SHA と対象・未確認範囲は VALIDATION.md の既存採用記録に区別して記載。今回これらの新規採用なし。
- [x] 単位7の採用時は、JSON v7 の正常復元・不正 ID/出典不一致/上限超過による全体拒否、小天体・衛星の表示集合、PTH 探査機、全天図・地平図の星座集合・星座絵・天の川、恒星名選択・明るさ、雲・夜景・大気、食と影・風景・時間操作・原地点IDについて共通側の試験を特定し、ラッパーからの検証結果と区別して記録する。
  - 判定: YES。UNIT7 の採用 SHA・共通側試験・ラッパー側の範囲は VALIDATION.md に既記録。今回の一括試験とは区別。
- [x] `VALIDATION.md` と gate の判定には実際の対象と実施結果だけを記録し、未検証の機能を検証済みと説明しない。
  - 判定: YES。今回のビルド、通常操作の確認範囲と未実施項目を VALIDATION.md に追記した。

## 不合格条件

- [ ] 失敗した検証を成功として報告する。
  - 該当: NO（今回確認した差分・操作で該当を確認していない）。
- [ ] 別リポジトリの内容を、同梱せずに本リポジトリに保存されたと扱う。
  - 該当: NO（今回確認した差分・操作で該当を確認していない）。

## 判定

NO

チェック済みは条件を満たすと判断した項目、未チェックは未実施・未確認または不合格条件に該当しない項目。旧記録は過去の対象に関する証拠であり、今回の一括試験成功を示さない。
