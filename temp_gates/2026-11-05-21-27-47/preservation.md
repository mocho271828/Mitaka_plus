# Gate: データ保全と登録範囲

## 目的

既存の天文データと原本を保持し、コードの許諾とデータ・旧アプリの許諾を混同しない。

## 判定条件

- [x] 動作に必要な Plus 版の天文データ・画像・関連ファイルは `resources/` にあり、他リポジトリや旧アプリのパスを必要としない。
  - 判定: YES。前回の同梱・単独 clone 検証は VALIDATION.md と temp_gates/2026-11-05-20-10-00/preservation.md に記録。今回 resources/ の Git 差分はない。
- [x] `resources/` 内の動作に必要なデータと画像は Git に登録され、clone に含まれる。
  - 判定: YES。前回の LFS および clone の記録を参照。今回 resources/ の Git 差分はない。今回新規 clone は未実施。
- [x] 元データは削除・上書きせず、同梱したデータは原本と比較して内容の一致を確認している。
  - 判定: YES。既存の原本との照合と地形データの出典・照合は VALIDATION.md、TERRAIN_PROVENANCE.md に記録。今回 resources/ の Git 差分はない。今回全資源の再照合は未実施。
- [x] 旧アプリ、Wine 環境、認証情報、ビルド生成物を Git に登録していない。
  - 判定: YES。今回の git status に該当品の追加なし。既登録範囲は前回の gate と採用記録を参照。
- [x] データを利用する処理は選択された `DATA_ROOT` を読み取り専用で参照し、変換・移動・更新しない。
  - 判定: YES。追加された恒星名の解決は選択された data path 内の star_names_HIP.dat を読み取る。資源を更新する変更は見当たらない。
- [x] 公式原本と第三者の著作権・許諾表示を改変せず、データの許諾をコードから推定していない。
  - 判定: YES。権利表示と資源に今回の差分はなく、README の権利の区別を維持。
- [x] リポジトリの公開範囲は変更していない。
  - 判定: YES。今回公開設定を変更する操作は行っていない。前回の private 確認以降の設定は今回再照会していない。
- [x] 独自追加を含むローカルデータを優先し、公開版のデータや件数で置換・切り詰めをしていない。
  - 判定: YES。今回 resources/ に変更なし。元データの置換・切り詰めを行う差分なし。

  - 判定: YES。既存の信頼済みローカル実行説明は README にあり、自動実行の追加なし。
- [x] 小天体・衛星の原文・順序・重複を保持し、表示集合を出典・原行または原ブロック番号で識別する。同名行を統合せず、集合の復元時は参照する出典の SHA-256・バイト数を照合する。
  - 判定: YES。出典行・重複と復元契約は前回 gate と VALIDATION.md に記録。今回これらの loader / 集合実装は変更していない。
- [x] 追加衛星の親位置と登録を出典・JD ごとに結び付け、重心補正を二重適用しない。瞬間楕円を将来の運動の積分結果と扱わず、未確定の時系・精度期間を保証しない。
  - 判定: YES。衛星 evaluator は変更なし。未確定の時系・精度は既存文書に記載。

  - 判定: YES。小天体の軌道評価・上限処理は変更なし。旧版との未確定事項は SMALL_BODY_PROVENANCE.md を参照。

  - 判定: YES。PTH 評価・描画の入力処理は変更なし。PPI の扱いは既存記録を参照。
- [x] 星座の略号と同略号の複数図形を保持し、全天図・地平図の CAB 星座絵への対応と、未対応の 3D 星座絵を区別する。
  - 判定: YES。星座 loader は変更なし。CAB と 3D の対応範囲は機能表と README に記載。
- [x] 観測地点の全出典、CAB の全点・index、emmap の原 bytes を共通 loader で保持し、公開データによる置換や元画像の再保存を行わない。
  - 判定: YES。地点・CAB・emmap の共通 loader と resources/ に差分なし。前回の保全記録を参照。
- [x] 地形・銀河は選択した版の原本を使い、欠損を別版から補わない。ただし、ユーザーが使用を承認した国立天文台の公式別配布による Earth・Mars 地形データは出典を明示して利用できる。旧 Plus のデータとの同一性が未確認であることを示し、月・水星へこの例外を拡張せず、第三者への再配布許可を推定しない。風景画像の失敗を別定義への再選択で隠さない。
  - 判定: YES。TERRAIN_PROVENANCE.md は承認された地球・火星データと未確認・非対象を区別。今回資源・地形取得実装に変更なし。
