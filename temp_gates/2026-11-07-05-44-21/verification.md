# Gate: ビルド・検証・変更管理

## 目的

同梱コードとデータの渡し方を、再現可能なビルドと検証で確認する。

## 判定条件

- [x] `make build` と `make test` が成功する。
- [x] データや同梱コードを変更した場合、同梱データを指定した `make data-test` と `make reference-test` が成功する。公式比較には CF96・自転・月・大気・食を含める。
- [x] `DATA_ROOT` は絶対パスの `data` ディレクトリとして受け取り、コアのデータテストにはその親ディレクトリを渡す。
- [x] `DATA_ROOT` の既定値は本リポジトリ内を指し、データ不足の場合は手順を示すエラーで停止する。
- [x] クリーンなビルドは Lua ソースのダウンロードや他リポジトリを必要としない。
- [x] 作業完了時に `git status`、変更ファイル、差分量を確認し、300 行以上の変更では原則 commit する。
- [x] commit 前に `/simplifier-lai` skill の利用可否と依存関係を確認し、利用できない場合は報告する。
- [x] gate 検証用コピーに判定を記録し、実施したテストと未実施の確認を作業報告へ残す。
- [x] 追加衛星・描画品質・全画面・HTML を採用する場合、共通側の対応試験と採用 SHA を特定する。HTML helper の構成、実 OS 通知、実機・複数画面など未確認の範囲を成功扱いしない。
- [x] 単位7の採用時は、JSON v7 の正常復元・不正 ID/出典不一致/上限超過による全体拒否、小天体・衛星の表示集合、PTH 探査機、全天図・地平図の星座集合・星座絵・天の川、恒星名選択・明るさ、雲・夜景・大気、食と影・風景・時間操作・原地点IDについて共通側の試験を特定し、ラッパーからの検証結果と区別して記録する。
- [x] `VALIDATION.md` と gate の判定には実際の対象と実施結果だけを記録し、未検証の機能を検証済みと説明しない。

## 不合格条件

- [ ] 失敗した検証を成功として報告する。
- [ ] 別リポジトリの内容を、同梱せずに本リポジトリに保存されたと扱う。

## 判定

YES

## 検証記録

macOS 26.6.2 / arm64、Apple clang 21.0.0、C++17/Objective-C ARC、-Wall -Wextra -Wpedantic -Werror で、基点 d7bae2c からの最終実装に対する make -j6 build、make -j6 test、make -j6 data-test、make -j6 reference-test、make -j6 smoke がすべて成功した。4ブラウザの controller 回帰は既存分を含め小天体81件・衛星69件・探査機62件・天体47件。実際の menuForEvent: と action dispatch により選択元の取り違えと検索・再読込・ページ切替後の誤適用を確認した。公式比較は CF96・自転・月・大気・食・天の川を含む。詳細は VALIDATION.md に記録した。

DATA_ROOT は本リポジトリの resources/data の絶対パスで、core テストには親ディレクトリを渡す。既存の不足時エラーと固定ソースの Lua ビルドを維持する。今回は既存 checkout でのビルドであり、クリーン環境を新設しての再検証ではない。追加衛星・全画面・HTML・単位7の新規採用はなく、従来の採用元と未確認範囲を維持する。

実装者と別担当によるコード・文書の確認を行い、Git 状態・ファイル・差分量を確認した。300行を超えるため、今回の変更とこの検証コピーだけを明示指定して commit する。新規依存はなく既存 AppKit と C++ モデルを使用する。/simplifier-lai は利用不可、利用可能な simplify-lai は LobbyAI 専用のため適用しない。旧 Plus との実動作比較と手動メニュー操作は未実施で、自動試験だけで旧版一致を主張しない。

不合格条件に該当しないため、同節のチェックボックスは未選択とした。
