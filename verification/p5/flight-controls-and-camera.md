# 離着陸の通常操作と地球近傍のカメラ

Windows Plus 1.5.4 build101013 では、同梱の[日本語メニュー](../../resources/scripts/gui_jp.lua)と[Sキー](../../resources/scripts/shortcuts_jp.lua)が `Camera:toggleModeTo()` を呼ぶ。[初期設定](../../resources/scripts/option.lua)はモード切替7.1秒、離陸倍率7.5、地平線モード。旧版の実行中にも秒数と倍率を読み戻した。[旧版の実測](legacy-zoom.tsv)

PR #8 の修正前（5692942）でデータを読み込んだ AppKit の地平図を開き、主画面に単独の S キーを送ると、飛行も投影変更も始まらなかった。対応するメニュー項目はなく、`Camera.modeDuration` を5秒にして「地平図から離陸」を押しても3.0564秒で完了した（地平図の投影1.2秒、3D上昇1.8秒）。

修正版では「着陸・離陸」メニュー、主画面の S キー、地平図から離陸するボタンと地平図へ戻るボタンが、同じモード切替と秒数を使う。Plus の原本と一致するデータ、JD 2451545.0 で、通常の `NSWindow` のイベント配送、メニューの選択、ボタンのクリックを通して操作した。既定の S キーは7.167秒、設定5秒のボタンは離陸5.054秒・帰還5.027秒、1.5秒に設定した帰還メニューは1.567秒。時間0ならアクションの戻り時点で目的モードに切り替わり飛行タイマーは停止していた。秒数はクリックの配信、実画面描画、主スレッドの完了観測を含む。地平図のテキスト編集中は `s` が通常の文字として入り、Shift＋S、長押しの反復、別窓の S で移動が始まらないことも確認した。各経路の終点を WindowServer にある同一 PID の AppKit ウィンドウから撮影した。[計測と画像 SHA-256](ui-controls.tsv)

## 旧版の物理高度と視線

- **高度。** 旧Plusの `Camera.zoom` は表示用の尺度。旧版の Lua `takeoffScale` は PE32 の `0x634f43` から `0x5aada0` に結び付けられ、離陸経路の `0x481b89–0x481b99` が半径とこの倍率を掛ける。地球では既定7.5×6,378.1366 km、保存値1.55026e−9 pc。旧配布の `mitaka.ini` の ScreenZ=217.3、ScreenW=180、ObjZ=400 と通常版のスケール換算を用いると、基準球からの高度は `7.5 R × (400+217.3)/2000 ≈ 14,765 km`。実際の旧画面の距離表示は 1.5e7 m（9.9e−5 AU）。地球外縁の半径404.47物理画素と地心位置も、この距離から画面中央を見た透視投影に整合した。統合版の地球プラネタリウムからの離陸では、同じ物理高度で地心を向く。[通常版のカメラ位置](../../vendor/mitaka/sources/official/mitaka_source/Mitaka/main.cpp)・[スケール換算](../../vendor/mitaka/sources/official/mitaka_source/Mitaka/mtk_screen.cpp)
- **時間。** 旧版の離陸 `0x481b35` は最初の尺度を0.01 Rに設定し、`0x481bcc` は7.5 Rを目的値にする。通常の帰還 `0x48354b–0x483570` は目的値0。双方が使う `0x7bfa90` の仮想表は `0x137f9fc`。更新関数 `0x7bfae0` は経過割合 u に対し `(1−cos(πu))/2` の重みで開始値と終了値を内分する。IAT `0xc27ee0` は libmmd.dll の `__libm_sse2_cos`。統合版はこの余弦曲線を使用し、地形上の2 mから連続して上昇する。旧版の最初の0.01 Rは高度に換算すると約19.7 kmであり、出発瞬間の段差は再現しない。
- **視線。** 旧版1.5.4の水平モードでは、地心距離 L が2 Rより遠ければ地心を向き、1.002 Rまで近づく間に元の地上仰角へ戻る。途中の重みは `(asin(1.002R/L)−asin(1.002/2))/(π/2−asin(1.002/2))` を0〜1に制限した割合 q から計算し、q≤0.5では `2q²`、それ以降は `1−2(1−q)²`。旧1.5.4自身の `0x4c7649–0x4c782e` で確認した。回転量は元の地上仰角＋90°にこの重みを掛けたもの。三鷹、仰角22.5°、停止した旧版で7.5 Rを含む8尺度を表示した。3.2 Rと1.62 Rの地点を示す緑の十字の中心は、同じウィンドウの y=789.55→987.39物理画素。地心からの見上げ角の差は8.8°で式に一致する。0.325 Rでも、黒い空から地球上縁が現れる中央付近の y=1005〜1014 は計算の1011付近だった。地上35°・45°の2画角でも、宇宙側の終点で半径と距離表示を確認した。[旧版の停止尺度](legacy-zoom.tsv)・[通常版の対応する表示処理](../../vendor/mitaka/sources/official/mitaka_source/Mitaka/mtk_draw_struct.cpp)

この対応は地球のモード切替に適用した。通常の惑星への単独飛行や、他の対象での `Camera.zoom` 全般の換算は、ここでの測定範囲に含まれない。

同じ緯度35.68°・東経139.76°でも、太陽系の3D地表からの離陸は従来の着陸・上昇操作を使う。統合作業の途中ではこの入口まで地平図用の離陸になり、高度14,764.59 km・天底に着いていた。通常のLuaモード切替を3D地表から実行すると従来の51,025.09 km（8 R）・仰角−80°に到着するよう、地平図からの入口だけが旧Plus用の上昇を選ぶようにした。地平図を出発した対照は同じ14,764.59 km・天底で、この修正前後で完成地図の全2,039,824画素が一致した。[二つの入口の実画面と画素差](earth-ascent-entry.tsv)

総合試験で、地球から月（緯度25°・東経−40°）への離陸を0.5秒で止め、同じ視点から再開すると、日時によって経路計算が失敗した。JD 2451501.600ではカメラは地表から4.16187 m上にあり、地球が最初の直線経路と横方向の迂回点への線の両方を遮った。従来の計算はこの同じ最初の区間に点を追加し続け、96点で打ち切っていた。この場合だけ元の視点からまず天体の半径方向に上昇し、その後のすべての辺で通常の衝突判定を行う。実データでJD 2451501.500から2451503.499まで0.001日刻みで再開すると、修正前は2,000日時中224件で拒否、修正後は2,000件すべてが24秒相当の96フレームで着地した。固定JDの回帰は修正前の経路で失敗し、修正後に出発姿勢の保持と月面到着を確認した。[再開の実データ回帰](../../vendor/mitaka/native/gui/tests/test_interplanetary_flight.cpp)
