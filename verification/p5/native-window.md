# 三鷹からの離陸・帰還を統合版の実ウィンドウで測定

測定表の `before` はネイティブ版 `5692942` の結果を示す。三鷹の北緯35.675°・東経139.54°を観測地点の入力欄に指定し、JD 2451545.0 で時計を停止した。選択対象は地球。基本条件は方位0°・高度22.5°・地平図の縦画角45°。個別の対照では方位70°・高度12°・地平図35°、あるいは地平図25°・宇宙図65°を使った。実行に用いた575ファイルは Plus 同梱の原本と照合したもの。描画モデルや地形データは通常の製品経路で読み込んだ。

macOS 26.6.2 / Apple M4 で、製品の AppController とビューを使う AppKit ウィンドウを開き、`Camera:setModeTo` に対応するホストアクションで往復した。追加で離陸・降下ボタンのアクションも実行した。表示モード・視野角・方位・対象のスクリプト参照値は Lua helper が使用する snapshot から取得し、地心距離と視線方向は同じフレームのカメラから別に求めた。投影途中の天体配置と地面はウィンドウ自身が描いたもの。SDSS や地表画像の表示設定も実測の条件に含む。

出発・操作受付直後・途中の複数時点・表示切替・停止・描画を待った終点を ScreenCaptureKit で撮影し、ウィンドウ番号、所有PID、表示中の状態を毎回照合した。Mac の他の全画面アプリとの切替で途中のキャプチャが欠けた試行は本表に含めなかった。比較に使用した連続画像は、WindowServer に測定中のみ追加した Retina ディスプレイ（3420×2224物理画素）に実ウィンドウを置いて取得した。ウィンドウは2560×2066物理画素。宇宙図の地図は1928×1058画素で、地平図の地図矩形は投影方法に応じて変化する。画素数は切り出した地図の実寸を使った。[実ウィンドウの画像ハッシュとフレームデータ](native-flight-frames.tsv)

画面取得はメインスレッドの次のタイマー通知を遅らせる場合がある。操作時間の比較は、別起動の同じ操作で撮影を止め、カメラの標本だけを取った試行に基づく。[タイマーとモード切替時刻](native-flight-time.tsv)。

## 比較対象の表示（5692942）

- 7.1秒の離陸では、最初の約2.9秒間は地平図の投影だけを変え、実際の高度を変えていなかった。宇宙図へ切り替えてから高度が上がり、終了時の地心距離は57,403.23 km、視線は地心から10°外れた。45°の地図で、地球は中心より約227物理画素下に見えた。
- そのまま降下すると、7.1秒指定では約4.35秒でモードを地表へ戻し、残りを地平図の投影変更に使った。地球の中心からの戻り方は同じでも、着地後の視線が−80°のままになった。出発時の高度22.5°に対して102.5°のずれがあり、地図の366,819画素でいずれかのRGB成分が12階調を超えて変わった。方位70°・高度12°の対照も同じ−80°に着地し、出発時と92°ずれた。
- 地平図25°・宇宙図65°で、ビュー自身の進行率0.8921895のフレームに地平図HUDが「42.8438°」と表示された。その時点の補間画角は60.6876°。HUD が透視側を45°に固定して計算していた。この差は停止後の表示よりも、離着陸中の画面で識別できる。

## 同じ操作でのネイティブ版の測定

| 条件 | 統合版の実測 |
| --- | --- |
| モード切替と所要時間 | 7.1秒指定では離陸命令が戻った時点（0.058秒）に宇宙モード。地表に近い区間は地平図を実地形に重ねて移動し、上昇が7.254秒で完了した。降下は到着と同時の7.162秒まで宇宙モードだった。3秒指定では離陸受付0.053秒、到着3.180秒、帰還の地上切替3.074秒。数値は各条件1回の実タイマー観測。 |
| 地表への帰還 | 7.1秒／3秒の正面（方位0°・高度22.5°）、および3秒の斜め（70°・12°・画角35°）の3経路とも、着地後の緯度経度、視線姿勢、画角が出発時に一致した。同一実ウィンドウ内で地平図各1,982,224画素を比較し、3経路すべてでRGB差0。旧版で同じ2姿勢を往復した結果も参照。[地図の全画素比較](native-ground-return.tsv)・[旧版の開始と終了](legacy-flight.md) |
| 宇宙到着時の地球 | 方位0°／高度22.5°から明示3秒で離陸。修正前の地心距離57,403.23 kmが21,142.73 kmになり、視線の地心からのずれは10°から0.000002°未満へ。選択輪を外した実地球の縁に合わせた円の半径は145.96→404.93物理画素、中心の垂直ずれは地図中央より227.43画素下→1.23画素上。原画の見かけの半径は旧版で約404〜409画素。ともに画角45°で縦1,058画素前後の比較。[輪郭測定](native-earth-limb.tsv) |
| 飛行中の命令 | 12秒離陸の約1.7秒後、高度665 kmで `forceMode(PLANETARIUM)` を実行した。地上モード・元の高度角22.5°へ即座に戻り、元の終了期限を過ぎた13秒後も地上のまま。別試行で上昇中に同じ宇宙モードを再要求した際は、高度686.80 kmから飛行が継続し、期限後は宇宙で停止した。[操作の前後の画面](native-flight-frames.tsv) |
| 異なる画角の重ね描き | 18秒の離陸を撮影。開始0.50秒、高度16.86 kmの時点で地平図25°・透視65°の補間から31.904593°を得た。画面上の地平図タイトルは31.9046°で、そのフレームでは後ろの宇宙タイトルを隠して文字の重なりを防いだ。[画面別の補間値、表示値、画像ハッシュ](native-horizon-fov.tsv) |

輪郭測定では、地球を選択したままの終点を撮影し、追従をオフにした同じカメラのまま選択を月へ移して追加撮影した。これにより白い選択輪を地球の縁として拾わずに済む。直後に地球を選び直して帰還した。画像の実際の座標から中心・半径を求める際は、地心からカメラまでの方向と画角で探索領域を決め、460方向の半径方向の輝度勾配を調べた。範囲端と弱い勾配は除いて円を当てはめた。最終版の採用431方向で半径方向残差の中央値は0.84画素、90パーセンタイルは6.82画素。雲や大気・照明・星の重なりがあるため、地球の物理半径を画像から精密に推定する測定には使っていない。

フレーム表の `view_segment` は地平図が2・宇宙図が1、`lua_mode` は地上が0・宇宙が1。修正前の `projection_timer` は地平図タイマー、修正後は地平図の重ね描き用に出発姿勢が保持されているかを示す。重ね描きの実際の可視性・不透明度は `horizon_visible` と `horizon_opacity`、物理的な視点方向は `view_azimuth_deg`・`view_altitude_deg` を使う。

## 3秒往復の再現性

同じ製品ビルドで、三鷹・JD 2451545の3秒往復を選択輪の有無も含めてもう一度撮影した。比較用の撮影と照合すると、出発と帰還は各1,982,224画素、宇宙到着時の地球は選択輪あり・なし各2,039,824画素で、地図のRGBがすべて一致した。地球の実測半径も404.9308物理画素で一致し、最終ビルド内でも出発と帰還の地図に差がなかった。[4画面の画素照合](native-final-relink.tsv)
