# Windows Plus 1.5.4 の離陸と帰還

2026-11-12、Windows Plus 1.5.4 build101013（作者配布の実行ファイル SHA-256 `48961f09019e0e43f23f2537752978dc16c563c807f5b048ba5b0448c0d2b457`）を Boxedwine 26R1 / Wine 11 / OSMesa で実行した。使用した Mac は Apple M4、macOS 26.6.2。旧アプリと Wine 環境のコピーへ、統合版の検証に使った Plus のデータ、画像、テクスチャを用意した。検証専用の三鷹地点を旧版の `Places:addPlace` で登録し、日時は JD 2451545.0（旧版ローカル表示 2000-01-01 21:00:00）、観測地は東経139.54°・北緯35.675°。通常の Camera メニューとショートカット、作者の `scripts/option.lua` を読み込んだ。[実行環境の出典](../p1-2-legacy-window.md)・[旧版の離着陸設定](../../resources/scripts/option.lua)

## 操作と画面の採取

- 旧版の S キーを OS のキーボードイベントで入力した。キーもメニューの Landing/Takeoff も同じ `Camera:toggleModeTo()` を実行する。離陸・帰還の両方で WindowServer の所有 PID とウィンドウ番号を照合し、通常ウィンドウを各46回撮影。離陸43枚、帰還44枚を取得できた。ウィンドウ画像を取得できなかった離陸3回・帰還2回も時刻と失敗状態を記録した。[Sキーの割当](../../resources/scripts/shortcuts.lua)・[メニューの割当](../../resources/scripts/gui.lua)・[連写記録](legacy-keyboard-frames.tsv)
- 別起動では、旧版のスクリプトエディタから `Camera:setModeTo(mode, seconds)` と `waitTime` を実行。出発、命令と同じコールバック内、複数の移動中、到着後に `Camera.mode` を直接読んだ。値を一時的な真偽フラグに写して `State:storeAsInit()` で保存し、直後にフラグを戻した。各状態の保存時刻をホストの単調時計で観測し、画像を撮影した。撮影後も同じ検証地点の番号であることを再確認。英語の地上HUDと宇宙HUDは表示項目が異なる。移動中の数値は保存した状態と、少し後に WindowServer が公開した実画面という時差を含む。各行に画像取得終了までの時間を記載した。[旧版77組のカメラ値と画像のハッシュ](legacy-flight-states.tsv)
- `modeDuration`・`takeoffScale` の getter を状態へ直接退避した独立実行でも、同梱設定の **7.1秒・7.5倍** を読み戻した。追加の12秒離陸中に強制帰還する試行と、地球を1 AU離れて通常帰還を指示する試行も行った。

## 地平図と宇宙モード

地上の表示は恒星と天球上の案内、HUD の「View Angle」と「View direction」。上昇に入るとHUDは「Distance」「Orientation」に切り替わり、視界が恒星から地表・地球の円盤へ移った。降下中は逆順。途中でズームが変わっても、宇宙で保存される基本姿勢の四元数は一定だった。開始地点や地上姿勢を変えた場合の四元数は状態表に含めた。

| 操作 | 旧版で確認した挙動 |
| --- | --- |
| 三鷹の地上から離陸 | 命令と同じコールバック内で `Camera.mode=HIPPARCOS`。開始の `Camera.zoom` は0.01地球半径相当、終了は7.5地球半径相当の `1.55026e−9 pc`。目標の地点IDを維持した。 |
| 同じ三鷹へ通常帰還 | 降下開始・途中はHIPPARCOS。完了して初めてPLANETARIUM、zoom=0。出発の方位・高度・画角を復元した。方位0°・高度22.5°・画角45°と、方位70°・高度12°・画角35°の2姿勢で、帰還後の地図領域1,690,684画素（x=41…1638、y=261…1318）のRGBすべてがそれぞれの出発時と一致した。 |
| 地点ではなく `Planet.Earth` を指定して同じ位置から離陸・帰還 | 宇宙でのターゲットは地心を表すID。宇宙到着時のzoom、HUD距離、地球の輪郭は地点IDの対照と整合した。帰還後のターゲットは `Planet.Earth.P5Mitaka` に戻った。出発との8,220画素の差は対象欄 x=599…1082、y=1063…1098に限られ、星空と姿勢は出発時と一致した。 |
| 上昇中の `forceMode(PLANETARIUM)` | 12秒離陸の途中で即座に地上を返し、先の離陸期限を過ぎても地上だった。この強制操作の保存zoomは `1.55026e−9 pc`、通常帰還の終点では0だった。 |
| 遠方からの通常帰還 | 地心ターゲット、1 AUで3秒の通常帰還を指示。待機後もHIPPARCOSで、zoomは原値 `4.84814e−6 pc`。 |

7.1秒の明示指定での旧版の読取例。時刻の原点は各離着陸命令直後の状態をホストが検出した時点。旧アプリの更新・スクリプトの呼び戻しとホストのポーリングを含むので、観測時刻の丸めから補間式を決めていない。

| 方向 | 命令から状態保存の観測まで（秒） | 対応する `Camera.zoom`（pc） |
| --- | --- | --- |
| 離陸 | 0、0.838、2.921、4.573、6.404、8.062 | 2.06701e−12、3.91119e−11、3.75063e−10、9.65022e−10、1.47034e−9、1.55026e−9 |
| 帰還 | 0、1.028、2.425、4.372、6.194、7.711 | 1.55026e−9、1.51462e−9、1.24668e−9、6.92288e−10、1.43035e−10、0 |

同じ実行ファイルの Lua 登録から、`setModeTo` のバインド `0x62d240`、モード判定 `0x5a5720`、離陸 `0x4819c0` と降下 `0x483420` を確認した。既定で有効な滑らかな補間では両方向から `0x7bfa90` に到達。更新関数 `0x7bfae0` は `0x7c1990` が経過時間と指定時間から求めた進捗 u に対し、`0x7bfb26…0x7bfb64` で `(1−cos(πu))/2` を使って開始zoomと終了zoomを補間する。定数 `0xcbc050` と `0xcbc048` の binary64 は π と 0.5、呼出先は `libmmd.dll!__libm_sse2_cos`。u=1の分岐は終了値を直接書く。強制切替の同一モード要求は判定 `0x5a5630…0x5a564a` で戻る。通常の時間指定は `0x5a5739…0x5a5747` で同一モードと進行中の再要求を弾く。離陸時の `0xc2bcb8` はbinary32の0.01をdoubleへ広げた値、降下の目標は0。手元のPE32を `xcrun llvm-objdump -d --x86-asm-syntax=intel` とPEの定数・インポート表で検査した。アドレスはImageBaseを含み、上記SHAに対応する。

## ズーム、画面に出た距離、地球の輪郭

三鷹からの離陸後、地球の見かけの大きさと HUD「Distance」を確認した。宇宙の終点では、旧Luaのzoomは約47,836 km相当、HUDは約1,500万 m（約9.9e−5 AU）。距離の表示を旧Luaのzoomと一対一に対応する物理高度として読み替えると画面の大きさに合わない。さらに同じ宇宙モードと日時・姿勢で `Camera.zoom` を明示設定し、30、15、7.5、3.2、1.62、0.325、0.065、0.01地球半径で停止して撮影した。8段階すべてで、指定したzoomの距離換算値に0.30865を掛けると、HUDに表示された2有効数字の距離と整合する。係数はこのウィンドウ構成での測定値。[8距離の画面と表示値](legacy-zoom.tsv)

- 7.5地球半径の終点で、画像の縦横方向の輝度勾配に沿って上側から外縁を取り、外れ値に頑健な円を当てはめた。標準Sキー離陸では中心 (838.29, 787.73)、半径404.47物理画素（302標本、円への残差中央値0.27 px）。独立した秒指定の両ターゲットでも円の半径が405.09 px前後、35°の地上画角からの離陸では406.53 pxだった。35°と45°の地上画角は、宇宙到着時の保存値でも35°と45°のまま。宇宙の円盤直径は地上の画角比に応じて拡大しなかった。
- 同じ旧版の小惑星画像を前回校正した透視投影では、深度係数3.25794、焦点係数4143.53から有効焦点距離は約1,272物理画素になる。この値を今回の円半径に適用し、球半径6,378 kmを仮定すると地心距離は約2.1万km、地球表面から約1.46万〜1.47万km。撮影ごとの描画差、地球の扁平、地形、大気で外縁は変わる。[旧版の投影を校正した条件](../p4/legacy-orbits.md)
