# 個別小惑星の楕円以外の要素と旧 Plus の注視方向

Windows Plus 1.5.4（SHA-256 `48961f09019e0e43f23f2537752978dc16c563c807f5b048ba5b0448c0d2b457`）のカメラが注視した高度を、同梱セレスの要素を元にした試験専用コピーで比較した。`P4Parab` は `e=1`、`P4Hyper` は `e=1.2` とし、それぞれ独立した対象番号を割り当てた。この2行は配布された実データにはない。旧画面・状態採取時の `Camera.target` は `Planet.Earth`。観測地点の緯度経度は保存値から直接は読み取れなかった。

元のセレス・イカルスの高度を JD 2451000.5 と 2451150.5 で読み、これら4値だけから地球上の有効観測地点を最小二乗で求めた。地球姿勢は以前の比較と同じ式で、地心位置は同梱 CF96 と月位置による地球中心補正を使った。有効地点は北緯10.191022°、東経179.999989°で、4高度の残差は最大0.000040°。指定試行のスクリプトに書かれた三鷹の緯度経度を代入すると、例えば初日のセレスは64.561°となり、実測39.343°に合わない。地点推定に使わなかったセレスの長半径1.5 AUの対照2件でも残差は0.000034°以下だった。[地球姿勢・観測地点の計算](../p1-2-legacy-attitude.md)・[全10件の入力時刻・保存状態のハッシュと残差](individual-conic-look.tsv)

| 比較対象 | 旧カメラ高度（元期 / 150日後） | 独立計算（同順） |
| --- | --- | --- |
| P4Parab、e=1 | −6.60144° / 54.9892° | −6.601446° / 54.989250° |
| P4Hyper、e=1.2 | −67.9355° / 33.0494° | −67.935448° / 33.049363° |
| 太陽中心のゼロ位置を返す対照 | — | 77.382298° / 57.690811° |

対象実行ファイルの数値計算 `0x4210c0` で `0x421106–0x42111a` は楕円、双曲線、等号の3分岐に入る。これを独立に式に起こし、元の軌道要素（旧版の binary32 丸めを反映）と同じ軌道面回転を適用した。

- **双曲線**では `M=(M0+n(t−epoch))π/180`、`e sinh H−H=M`、軌道面座標は `x=a(e−cosh H)`、`y=a sqrt(e²−1) sinh H`。本条件では旧版注視高度との最大差は0.000052°だった。
- **等号分岐**は `0x42111a–0x4211d4`。この2条件の正の引数について、`m=(M0+n|t−epoch|)π/180`、`u=tan(atan(2/(3m))/2)^(1/3)`、`D=1−u`、`x=a(1−D²)`、`y=2aD` が旧版注視高度を再現した。通常の放物線式の `D=1/u−u` を用いた対照は −73.010724° / 43.047451°だった。別版の公式 Mitaka 1.3.1 の `calc_orbital_pos` は等号でゼロを返す。[通常版の参照ソース](../../vendor/mitaka/sources/official/mitaka_source/common/astro/cele_mech.cpp)

同じ旧実行ファイルを別起動し、以前の元期・地点のほか、符号と回転数を区別できる2日時で実測した。P4Hyper の JD 2449600.5（M 約−50.3°）の保存高度は−31.81160°、JD 2451660.5（M 約391.0°）は−6.25138°。運動を折り返さない計算とはそれぞれ0.000018°、0.000012°差、Mを0〜360°に折り返した対照とはそれぞれ10.215°、5.934°違う。旧実行ファイルの `0x4210df–0x421114` も平均近点角を剰余計算せず双曲線分岐へ渡す。別途、P4Hyperの `a` 行を等価な `n=0.21423154438883094` に置き換え、異なる番号980008を付けた試験行で、旧版の注視方位・高度は元期・150日後とも a 指定と表示全桁が一致した。[追加2日時と対照](individual-conic-extra.tsv)・[a と n の旧版実測](individual-hyper-motion.tsv)

統合版は個別小惑星・TNOの e>1 の瞬時位置に既存の双曲線解法を適用する。実ウィンドウで試験入力を選択して注視し、同じカメラで「天体点」「天体点＋軌道」「非表示」を撮影した。双曲線は中央に点を表示し、軌道を切り替えても地図に変化はなく、標本数は0、周期なしの診断を返した。e=1 は点・軌道とも表示せず、packed 36 の非楕円や未認定の 37 byte へは拡張していない。旧版の測定は注視点の方向であり、非周期運動の画面上の軌道線・標本時刻・打ち切り範囲は未確定。[統合版の実画面・表示切替・ハッシュ](individual-conic-native.tsv)

双曲線の位置評価を追加した際、有限だが極端な入力で計算自体の不具合も再現した（実データ57定義に該当なし）。a=1 AU、e=10³⁰、元期の M=1°、回転なしで、修正前の位置を逆算すると M=23,141.58°。双曲線離心近点角 H が非常に小さく、二分法の絶対停止幅で正しい解を見失っていた。高次項が丸め誤差未満のときは H=M/(e−1) を使用する。e=1.2 の近日点直前の微小な負の角とともに[天文計算の回帰試験](../../vendor/mitaka/native/core/tests/test_astronomy.cpp)で確認した。
