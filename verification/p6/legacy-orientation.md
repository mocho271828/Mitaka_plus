# Windows Plus 1.5.4 の姿勢 API 実測

作者配布の Windows Plus 1.5.4 build101013 を Boxedwine 26R1、Wine 11、OSMesa で起動し、同梱データを使って JD 2451545.0、対象 Planet.Earth、Camera.zoom=1 AU とした。宇宙モードで Camera:setEuler(0,0,0) のあと Camera:setEuler(30,20,35) を実行し、保存状態と実ウィンドウを取得した。実行ファイルの SHA-256 と環境は[前回の旧版比較](../p5/legacy-flight.md)と同じ。

## 直接読み戻し

Camera:getOrient() の値は、各成分に1を加えて100万倍し、整数として Time.speed に代入して状態保存した。Camera:getEuler() は各成分に360を加えて1000倍した。時間速度の保存値は整数であり、この方法の量子化はそれぞれ 0.000001 と 0.001 度。測定のための速度設定は作業用アプリだけに適用した。[各成分の保存値、状態・画像ハッシュ](legacy-orientation-readback.tsv)

直接取得した四元数 (x,y,z,w) は (+0.083322,+0.293527,−0.328911,+0.893709)、オイラー角は (30.000°,20.000°,35.000°)。状態保存の Camera:setOrient も (0.0833221,0.293528,−0.32891,0.89371) で、直接getterと同符号だった。

実画面HUDの Position of Viewpoint は、姿勢変更前がおよそ (−2.65e10,1.45e11,4.62e10) m、変更後が (−4.80e9,1.29e11,3.76e10) m。地球の対象位置は約 (−2.65e10,1.45e11,0) m のままで、HUDの距離はいずれも 4.6e10 m。この条件の姿勢変更では対象の周囲を視点が移動した。HUDは2〜3桁表示である。画像は direct/space-before.png と direct/space-instant.png。

## 時間指定の補間

旧版の同一Luaスクリプトから Camera:setEulerTo(30,20,35,20) を起動し、waitTime を使って同一プロセス内で状態を保存した。開始からの経過はホストの単調時計で状態ファイルの更新を検出した時刻で、開始のショートカット処理と保存・画面撮影の遅延を含む。状態保存と画像取得の完了時間は一致せず、厳密な同時刻の画像として扱わない。

| 状態検出時の経過秒 | 保存された (x,y,z,w) |
| ---: | --- |
| 0.21 | (0, 0, 0, 1) |
| 3.29 | (0.0092775, 0.0144319, -0.0167886, 0.999712) |
| 6.34 | (0.0332422, 0.0576499, -0.0665431, 0.995562) |
| 9.52 | (0.0602952, 0.124165, -0.141881, 0.980213) |
| 12.63 | (0.0777933, 0.196235, -0.222196, 0.951877) |
| 17.63 | (0.0837769, 0.280784, -0.315032, 0.902716) |

同じ版の実画面6枚と保存状態の SHA-256、画面取得結果、撮影終了時刻は[時系列表](legacy-orientation-animation.tsv)。

地平図では北緯35.675°、東経139.54°、方位0°・仰角22.5°・画角45°から、方位70°・仰角12°への即時変更と4秒指定を実行し、終了後の保存状態が同じ方位70°・仰角12°となることを確認した。実画面と状態は検証 Mac の direct/ground-*.png・.lua。追加で地平図から Camera:setEuler(30,20,35) を実行した。保存される宇宙姿勢は目標四元数に変わったが、方位0°・仰角22.5°とウィンドウの全1920×1504画素は不変だった。地上姿勢を初期化し、Camera:setEulerTo(30,20,35,4) を実行した場合、約4.8秒後も地上の画像・保存された四元数とも不変だった。[実画面と状態のハッシュ](legacy-ground-euler.tsv)。旧マニュアルはこれらを宇宙モードのAPIとして記述している。

地平図の方位と高度も20秒指定で同一Luaスクリプトから連続実行した。保存時刻3.25秒では方位3.82726°・仰角21.9259°、9.40秒では30.4552°・17.9317°、17.65秒では67.06°・12.441°。同じ条件の実画面と撮影時刻は[地平方向の時系列表](legacy-horizon-animation.tsv)。

宇宙のロール単軸でも、同じ対象・元期から Camera:setEulerTo(0,0,90,20) を実行した。保存状態の四元数は3.38秒で (0,0,−0.0456581,0.998957)、9.50秒で (0,0,−0.337746,0.941237)、17.70秒で (0,0,−0.684207,0.729288)。[実画面と状態の時系列](legacy-roll-animation.tsv)。
